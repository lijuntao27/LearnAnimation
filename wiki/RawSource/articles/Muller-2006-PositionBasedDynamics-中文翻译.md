## 摘要

计算机图形学中最流行的动态系统仿真方法是基于力的（force based）：累积内力与外力，按牛顿第二定律由力计算加速度，再用时间积分方法更新速度、最终更新物体位置。少数仿真方法（多数刚体模拟器）使用基于冲量（impulse based）的动力学，直接操作速度。本文提出一种**同时省去速度层、直接作用于位置**的方法。基于位置的方法的主要优势是**可控性**：可以避免显式积分方案在力基系统中的过冲问题；此外碰撞约束易于处理，穿透可以通过把点投影到有效位置而被**完全消除**。我们用该方法构建了一个实时布料模拟器，它是面向游戏的物理软件库的一部分。这一应用展示了该方法的优势与长处。

**分类与主题描述**（ACM CCS）：I.3.5 [计算机图形学]：计算几何与对象建模—物理建模；I.3.7 [计算机图形学]：三维图形与真实感—动画与虚拟现实。

## 1. 引言

计算机图形学中基于物理的动画研究，关注为刚体动力学、可变形物体或流体流动等物理现象寻找新的仿真方法。与以精度为主要目标的计算科学不同，这里的核心议题是**稳定性、鲁棒性与速度**，同时结果应保持视觉可信。因此计算科学的现有方法无法一一照搬——事实上，在图形学中研究基于物理仿样的主要理由，正是提出贴合本领域特殊需求的专门化方法。我们提出的方法属于这一类。

仿真动态对象的传统途径是基于力的：每个时间步开始时累积内力与外力。可变形物体中的弹性力、流体中的黏性与压力是内力的例子；重力与碰撞力是外力的例子。牛顿第二定律通过质量把力与加速度联系起来。于是利用顶点的密度或集总质量，力被转换为加速度。随后任意时间积分方案都可以先由加速度算出速度、再由速度算出位置。另一些方法用**冲量**而非力来控制动画——因为冲量直接改变速度，可以省去一层积分。

在图形学、尤其是游戏领域，**直接控制物体或网格顶点的位置**往往是刚需：用户可能想把某个顶点附着到运动学对象上，或确保顶点始终位于碰撞物体之外。我们提出的方法直接作用于位置，使这类操作变得容易。此外，基于位置的方法可以直接控制积分过程，从而避免与显式积分相关的过冲与能量增益问题。基于位置的动力学的主要特性与优势是：

- 基于位置的仿真给出对显式积分的控制，消除了典型的不稳定性问题；
- 顶点与物体各部分的位置可以在仿真过程中被直接操纵；
- 我们提出的公式化允许在位置基框架下处理**一般约束**；
- 显式的位置基求解器易于理解与实现。

## 2. 相关工作

近期的技术发展水平报告 [NMK∗05] 对图形学中可变形物体仿真方法（质点-弹簧系统、有限元法、有限差分法等）做了很好的综述。除 [MHTG05] 的引用外，基于位置的动力学并未出现在该综述中；但位置基方法的部分思想曾以各种形式出现在多篇论文里，既没有为之命名，也没有定义完整框架。

**Jakobsen [Jak01]** 的 Fysix 引擎建立位置基方法之上。他的核心思想是使用 Verlet 积分器并直接操纵位置。由于速度隐式存储于当前位置与先前位置之差，位置操纵也就隐式更新了速度。他主要关注距离约束，对更一般的约束如何处理只给出了模糊提示。本文给出处理一般约束的完全一般化方法。我们还关注**线动量与角动量守恒**这一重要议题。我们使用显式速度而非存储先前位置，这让阻尼与摩擦的仿真容易得多。

**Desbrun [DSB99] 与 Provot [Pro95]** 在质点-弹簧系统中使用约束投影来防止弹簧过度拉伸。与完整的位置基方法不同，投影只作为对拉伸过度弹簧的"打磨"工序，而非基本仿真方法。

**Bridson et al. [BFA02]** 用传统力基方法做布料仿真，并结合基于位置的几何碰撞消除算法，确保碰撞修正冲量保持在稳定界限内。Volino et al. [VCMT95] 提出的运动学碰撞修正步骤同理。

**Clavet et al. [CBP05]** 用位置基方法仿真黏弹性流体。他们的方法并非完全位置基：时间步出现在位置投影的多个地方，因此积分只如常规显式积分一样**条件稳定**。

**Müller et al. [MHTG05]** 通过把点移向由静止状态与当前状态形状匹配得到的的目标位置来仿真可变形物体。他们的积分方法与我们提出的最接近，但只处理一种专门化的全局约束，因此不需要位置求解器。

**Fedor [Fed05]** 用 Jakobsen 的方法在游戏中仿真角色，针对人体角色这一特定问题调优，用多套骨架表示并通过投影保持同步。**Faure [Fau98]** 通过修改位置而非速度来使用 Verlet 积分——新位置通过对约束线性化求得，而我们直接作用于**非线性约束函数**。

我们像 [BW98] 和 [THMG04] 一样用约束函数定义一般约束，但不通过约束函数能量的导数来计算力，而是**直接求解平衡构型并投影位置**。由此推导出的布料弯曲项与 [GHDS03]、[BMF03] 的类似，但适配于点基方法。

第 4 节我们把位置基动力学用于布料仿真。布料仿真近年来是图形学的活跃研究领域，与其逐一引用关键论文，请读者参阅 [NMK∗05] 的综合综述。

## 3. 基于位置的仿真

本节给出一般化的位置基方法。随后在布料仿真与结果章节中给出该方法的特定应用。我们考虑三维世界，但该方法在二维同样适用。

### 3.1. 算法总览

我们用 $N$ 个顶点与 $M$ 个约束表示一个动态对象。顶点 $i \in [1, ..., N]$ 具有质量 $m_i$、位置 $x_i$ 与速度 $v_i$。约束 $j \in [1, ..., M]$ 由以下要素构成：

- 基数 $n_j$，
- 函数 $C_j: \mathbb{R}^{3n_j} \to \mathbb{R}$，
- 索引集合 $\{i_1, ..., i_{n_j}\}$，$i_k \in [1, ..., N]$，
- 刚度参数 $k_j \in [0...1]$，以及
- 等式或不等式类型。

类型为等式的约束 $j$ 满足于 $C_j(x_{i_1}, ..., x_{i_{n_j}}) = 0$；类型为不等式时满足于 $C_j(x_{i_1}, ..., x_{i_{n_j}}) \geq 0$。刚度参数 $k_j$ 定义约束强度，取值范围 0 到 1。

基于这些数据与时间步 $\Delta t$，动态对象的仿真流程如下（译注：原文行号 1–17）：

```text
(1)  forall vertices i
(2)      initialize x_i = x_i^0, v_i = v_i^0, w_i = 1/m_i
(3)  endfor
(4)  loop
(5)      forall vertices i do v_i ← v_i + Δt w_i f_ext(x_i)
(6)      dampVelocities(v_1, ..., v_N)
(7)      forall vertices i do p_i ← x_i + Δt v_i
(8)      forall vertices i do generateCollisionConstraints(x_i → p_i)
(9)      loop solverIterations times
(10)         projectConstraints(C_1, ..., C_{M+M_coll}, p_1, ..., p_N)
(11)     endloop
(12)     forall vertices i
(13)         v_i ← (p_i − x_i) / Δt
(14)         x_i ← p_i
(15)     endfor
(16)     velocityUpdate(v_1, ..., v_N)
(17) endloop
```

行 (1)–(3) 只是初始化状态变量。位置基动力学的核心思想体现在行 (7)、(9)–(11) 与 (13)–(14)。行 (7) 用一步显式 Euler 积分计算顶点新位置的估计 $p_i$。迭代求解器 (9)–(11) 操纵这些位置估计使其满足约束——做法是按 Gauss-Seidel 方式反复投影每个约束（见 3.2 节）。行 (13)–(14) 把顶点移动到优化后的估计位置，并相应更新速度。这与 Verlet 积分加当前位置修改 [Jak01] 完全对应，因为 Verlet 方法把速度隐式存储为当前位置与上一位置之差；不过，使用显式速度让我们能以更直观的方式操纵速度。

速度在行 (5)、(6)、(16) 被操纵。行 (5) 允许在部分力无法转换为位置约束时接入外力——我们只用它加重力，此时该行变为 $v_i \leftarrow v_i + \Delta t\, g$，$g$ 为重力加速度。行 (6) 在必要时阻尼速度——3.5 节展示如何施加**不影响物体刚体模式**的全局阻尼。行 (16) 依据摩擦与恢复系数修改碰撞顶点的速度。

给定约束 $C_1, ..., C_M$ 在整个仿真中固定不变；此外，行 (8) 生成随时间步变化的 $M_{coll}$ 个碰撞约束。行 (10) 的投影步骤同时考虑固定约束与碰撞约束。

该方案是**无条件稳定**的：积分步 (13)–(14) 不像传统显式方案那样盲目外推未来，而是把顶点移动到约束求解器算出的物理有效构型 $p_i$。唯一可能的不稳定源是求解器本身——它用 Newton-Raphson 方法求解有效位置（见 3.3 节）——但其稳定性不依赖时间步长，而依赖约束函数的形状。

这种积分既不能明确归入隐式也不能归入显式方案。每个时间步只做一次求解器迭代时，它更像显式方案；而增加迭代次数，受约束系统可以变得任意刚硬，算法行为就更像隐式方案。增加迭代次数会把瓶颈从碰撞检测移到求解器。

### 3.2. 求解器

求解器的输入是 $M + M_{coll}$ 个约束与各点新位置的估计 $p_1, ..., p_N$。求解器试图修改这些估计使它们满足所有约束。所得方程组是**非线性**的——即使简单的距离约束 $C(p_1, p_2) = |p_1 - p_2| - d$ 也给出非线性方程；此外不等式类型约束还带来不等式。为求解这样一般化的方程与不等式集合，我们使用 **Gauss-Seidel 型迭代**。原始 Gauss-Seidel 算法（GS）只能处理线性系统，我们借用的是 GS "逐个独立求解每个约束"的思想。但与 GS 不同，求解一个约束是非线性操作。我们反复遍历所有约束，把粒子投影到单独考虑该约束时的有效位置。与 Jacobi 型迭代不同，对点位置的修改**立即可见**于后续过程，这显著加速收敛——压力波可以在单个求解器步内穿越材质传播，这一效应依赖于约束求解的顺序。在过约束情形下，若顺序不保持恒定，过程可能导致振荡。

### 3.3. 约束投影

按约束投影一组点，即移动这些点使其满足约束。在仿真循环内直接移动点，最重要的问题是**线动量与角动量守恒**。设 $\Delta p_i$ 为顶点 $i$ 被投影移动的位移。线动量守恒要求

$$\sum_i m_i \Delta p_i = 0, \tag{1}$$

等价于保持质心不变。角动量守恒要求

$$\sum_i r_i \times m_i \Delta p_i = 0, \tag{2}$$

其中 $r_i$ 是 $p_i$ 到任意公共旋转中心的距离。若投影违反其中之一，就会引入所谓**幽灵力（ghost forces）**——像外力一样拖拽、旋转物体。不过只有**内部约束**需要守恒动量；碰撞或附着约束允许对物体产生全局效果。

我们提出的约束投影方法对内部约束同时守恒两种动量。同样地，点基方法更直接——可以直接使用约束函数，而力基方法需经由能量项导出力（见 [BW98, THMG04]）。考虑作用于点 $p_1, ..., p_n$、约束函数为 $C$、刚度为 $k$、基数为 $n$ 的约束。令 $p$ 为拼接向量 $[p_1^T, ..., p_n^T]^T$。对内部约束，$C$ 与刚体模式（平移与旋转）无关：旋转或平移这些点不改变约束函数的值。因此梯度 $\nabla_p C$ 垂直于刚体模式，因为它是最大变化方向。若修正量 $\Delta p$ 选在 $\nabla_p C$ 方向上，且所有质量相等，则两种动量自动守恒（不同质量稍后处理）。给定 $p$，我们要找修正量 $\Delta p$ 使得 $C(p + \Delta p) = 0$。该方程可近似为

$$C(p + \Delta p) \approx C(p) + \nabla_p C(p) \cdot \Delta p = 0. \tag{3}$$

把 $\Delta p$ 限制在 $\nabla_p C$ 方向上，即选择标量 $\lambda$ 使得

$$\Delta p = \lambda \nabla_p C(p). \tag{4}$$

> **图 2**：约束 $C(p_1, p_2) = |p_1 - p_2| - d$ 的投影。修正量 $\Delta p_i$ 按逆质量 $w_i = 1/m_i$ 加权。

把式 (4) 代入式 (3)，解出 $\lambda$ 再代回式 (4)，得到 $\Delta p$ 的最终公式

$$\Delta p = -\frac{C(p)}{|\nabla_p C(p)|^2} \nabla_p C(p) \tag{5}$$

这是对单个约束给出的非线性方程做迭代求解的一步**标准 Newton-Raphson 步**。对单个点 $p_i$ 的修正为

$$\Delta p_i = -s \nabla_{p_i} C(p_1, ..., p_n), \tag{6}$$

其中缩放因子

$$s = \frac{C(p_1, ..., p_n)}{\sum_j |\nabla_{p_j} C(p_1, ..., p_n)|^2} \tag{7}$$

对所有点相同。若各点有不同质量，我们用逆质量 $w_i = 1/m_i$ 加权修正量 $\Delta p_i$。此时例如无限质量的点（$w_i = 0$）如预期那样不移动。于是式 (4) 替换为 $\Delta p_i = \lambda w_i \nabla_{p_i} C(p)$，缩放因子变为

$$s = \frac{C(p_1, ..., p_n)}{\sum_j w_j |\nabla_{p_j} C(p_1, ..., p_n)|^2} \tag{8}$$

最终修正为

$$\Delta p_i = -s\, w_i \nabla_{p_i} C(p_1, ..., p_n). \tag{9}$$

举一个例子，考虑距离约束函数 $C(p_1, p_2) = |p_1 - p_2| - d$。对各点的导数为 $\nabla_{p_1} C(p_1, p_2) = n$、$\nabla_{p_2} C(p_1, p_2) = -n$，其中 $n = \frac{p_1 - p_2}{|p_1 - p_2|}$。缩放因子 $s = \frac{|p_1 - p_2| - d}{w_1 + w_2}$，最终修正为

$$\Delta p_1 = -\frac{w_1}{w_1 + w_2} (|p_1 - p_2| - d)\, \frac{p_1 - p_2}{|p_1 - p_2|} \tag{10}$$

$$\Delta p_2 = +\frac{w_2}{w_1 + w_2} (|p_1 - p_2| - d)\, \frac{p_1 - p_2}{|p_1 - p_2|} \tag{11}$$

这正是 [Jak01] 提出的距离约束投影公式（见图 2）——它们作为一般约束投影方法的特例自然出现。

到此我们尚未考虑约束的类型与刚度 $k$。类型处理很直接：等式类型总是执行投影；不等式类型只在 $C(p_1, ..., p_n) < 0$ 时投影。纳入刚度参数有多种方式，最简单的变体是把修正量 $\Delta p$ 直接乘以 $k \in [0...1]$。但求解器多轮迭代下，$k$ 的效果是非线性的：单条距离约束经 $n_s$ 次求解器迭代后的残余误差为 $\Delta p (1-k)^{n_s}$。为得到线性关系，我们不直接乘 $k$ 而是乘 $k' = 1-(1-k)^{1/n_s}$。经此变换，误差变为 $\Delta p (1-k')^{n_s} = \Delta p (1-k)$——如所期望的那样随 $k$ 线性、与 $n_s$ 无关。**然而所得的材料刚度仍依赖仿真时间步**。实时环境通常使用固定时间步，这种依赖不构成问题（译注：时间步/迭代依赖正是 [[Macklin-2016-XPBD|XPBD]] 2016 年要根治的缺陷）。

### 3.4. 碰撞检测与响应

位置基方法的一个优势是碰撞响应实现之简单。仿真算法的行 (8) 生成 $M_{coll}$ 个碰撞约束。前 $M$ 个由物体表示给出的约束全程固定，额外的 $M_{coll}$ 个约束则每个时间步从头生成，其数量随碰撞顶点数变化。**连续**与**静态**碰撞都能处理。连续碰撞处理：对每个顶点 $i$ 测试射线 $x_i \to p_i$。若该射线进入某物体，计算入射点 $q_c$ 及该处表面法线 $n_c$，向约束列表添加约束函数为 $C(p) = (p - q_c) \cdot n_c$、刚度 $k = 1$ 的不等式约束。若射线 $x_i \to p_i$ 完全位于物体内部，说明连续碰撞检测在某处已失效，此时回退到静态碰撞处理：计算离 $p_i$ 最近的表面点 $q_s$ 及该处法线 $n_s$，添加约束函数 $C(p) = (p - q_s) \cdot n_s$、刚度 $k = 1$ 的不等式约束。碰撞约束的生成在求解循环**之外**完成，这让仿真快得多。但某些场景下，求解器使用固定的碰撞约束集可能漏掉碰撞——幸运的是，据我们的经验，伪影可以忽略。

摩擦与恢复可以通过算法行 (16) 操纵碰撞顶点的速度来处理：对每个生成了碰撞约束的顶点，将其速度沿碰撞法线方向反射、垂直于法线方向阻尼。

上述碰撞处理只对**与静态物体的碰撞**正确，因为没有冲量传递给碰撞对方。两个动态物体间的正确响应可以通过用我们的模拟器同时仿真两者实现——即算法输入的 $N$ 个顶点与 $M$ 个约束简单地表示两个或更多独立物体。此时若一个物体的点 $q$ 穿过另一物体的三角形 $p_1, p_2, p_3$，我们插入约束函数为 $C(q, p_1, p_2, p_3) = \pm (q - p_1) \cdot [(p_2 - p_1) \times (p_3 - p_1)]$ 的不等式约束，使点 $q$ 保持在三角形的正确一侧。由于该约束函数与刚体模式无关，它会正确守恒线动量与角动量。碰撞检测变得略复杂，因为四个顶点都以射线 $x_i \to p_i$ 表示，需要检测**运动点与运动三角形**的碰撞（见布料自碰撞一节）。

### 3.5. 阻尼

仿真算法的行 (6) 在速度用于预测新位置之前对其阻尼。任何形式的阻尼都可以使用，文献中已提出多种方法（见 [NMK∗05]）。这里我们提出一个具有有趣性质的新方法：

```text
(1) x_cm = (∑_i x_i m_i) / (∑_i m_i)
(2) v_cm = (∑_i v_i m_i) / (∑_i m_i)
(3) L = ∑_i r_i × (m_i v_i)
(4) I = ∑_i r̃_i r̃_i^T m_i
(5) ω = I^{−1} L
(6) forall vertices i
(7)     Δv_i = v_cm + ω × r_i − v_i
(8)     v_i ← v_i + k_damping Δv_i
(9) endfor
```

其中 $r_i = x_i - x_{cm}$，$\tilde{r}_i$ 是满足 $\tilde{r}_i v = r_i \times v$ 的 3×3 矩阵（译注：叉积矩阵），$k_{damping} \in [0...1]$ 是阻尼系数。行 (1)–(5) 计算系统的全局线速度 $v_{cm}$（译注：原文写作 $x_{cm}$，应为笔误）与角速度 $\omega$；行 (6)–(9) 只阻尼各速度 $v_i$ 相对全局运动 $v_{cm} + \omega \times r_i$ 的**个体偏差** $\Delta v_i$。于是在极端情形 $k_{damping} = 1$ 下，只有全局运动存活，顶点集合表现为刚体；对任意 $k_{damping}$ 值，速度被全局阻尼，但**不影响顶点的全局运动**。

### 3.6. 附着

用位置基方法把顶点附着到静态或运动学对象非常简单：把顶点位置直接设为静态目标位置，或每个时间步更新为与运动学对象位置重合。为确保包含该顶点的其他约束不再移动它，把它的逆质量 $w_i$ 设为零。

## 4. 布料仿真

我们用点基动力学框架实现了一个面向游戏的实时布料模拟器。本节讨论布料特有的问题，同时为上一节引入的一般概念给出具体实例。

### 4.1. 布料的表示

布料模拟器接受任意三角形网格输入。唯一限制是网格须为流形（每条边至多被两个三角形共享）。网格每个节点成为一个仿真顶点。用户提供面密度 $\rho$（kg/m²），顶点质量取其相邻三角形质量的各三分之一之和。对每条边生成**拉伸约束**，约束函数

$$C_{stretch}(p_1, p_2) = |p_1 - p_2| - l_0,$$

刚度 $k_{stretch}$、等式类型；标量 $l_0$ 是边的初始长度，$k_{stretch}$ 是用户提供的全局参数，定义布料的拉伸刚度。对每对相邻三角形 $(p_1, p_3, p_2)$ 与 $(p_1, p_2, p_4)$ 生成**弯曲约束**，约束函数

$$C_{bend}(p_1, p_2, p_3, p_4) = \arccos\left( \frac{(p_2 - p_1) \times (p_3 - p_1)}{|(p_2 - p_1) \times (p_3 - p_1)|} \cdot \frac{(p_2 - p_1) \times (p_4 - p_1)}{|(p_2 - p_1) \times (p_4 - p_1)|} \right) - \phi_0,$$

刚度 $k_{bend}$、等式类型。标量 $\phi_0$ 是两三角形的初始二面角，$k_{bend}$ 是定义布料弯曲刚度的全局用户参数（见图 4）。

> **图 4**：弯曲阻力使用约束函数 $C(p_1, p_2, p_3, p_4) = \arccos(n_1 \cdot n_2) - \phi_0$。实际二面角 $\phi$ 以两三角形法线之间的夹角度量。

这一弯曲项优于"在 $p_3$、$p_4$ 之间加距离约束"或 [GHDS03] 的弯曲项之处在于：**它与拉伸无关**——该项不依赖边长。这样，用户可以指定"低拉伸刚度 + 高弯曲阻力"的布料（见图 3）。

式 (10)(11) 给出拉伸约束的投影；附录 A 推导弯曲约束的投影公式。

### 4.2. 与刚体的碰撞

与刚体的碰撞处理按 3.4 节所述进行。为获得双向交互，每当顶点 $i$ 因与某刚体碰撞而被投影时，就在接触点向刚体施加冲量 $m_i \Delta p_i / \Delta t$。只测试布料顶点的碰撞并不够——小刚体可能穿过大布料三角形，因此刚体的凸角点对布料三角形的碰撞也要测试。

### 4.3. 自碰撞

假设所有三角形尺寸大致相同，我们用**空间哈希**（spatial hashing）[THM∗03] 查找点-三角形碰撞。若顶点 $q$ 移动穿过三角形 $p_1, p_2, p_3$，使用约束函数

$$C(q, p_1, p_2, p_3) = (q - p_1) \cdot \frac{(p_2 - p_1) \times (p_3 - p_1)}{|(p_2 - p_1) \times (p_3 - p_1)|} - h, \tag{12}$$

其中 $h$ 是布料厚度（见图 5）。若顶点从三角形法线负侧进入，约束函数须为

$$C(q, p_1, p_2, p_3) = (q - p_1) \cdot \frac{(p_3 - p_1) \times (p_2 - p_1)}{|(p_3 - p_1) \times (p_2 - p_1)|} - h \tag{13}$$

以保持顶点在原来一侧。投影这些约束守恒线动量与角动量——这对布料自碰撞至关重要，因为它是**内部过程**。图 6 展示了一块自碰撞后处于静止状态的布料。若布料进入缠结状态，仅测试连续碰撞是不够的，须应用 [BWK03] 一类的方法。

> **图 5**：约束函数 $C(q, p_1, p_2, p_3) = (q - p_1) \cdot n - h$ 确保 $q$ 保持在三角形 $p_1, p_2, p_3$ 上方、距离为布料厚度 $h$。

### 4.4. 布料气球

对封闭三角形网格，网格内部过压可以轻易建模（见图 7）。我们向约束集合添加一个涉及网格全部 $N$ 个顶点的等式约束，约束函数

$$C(p_1, ..., p_N) = \left( \sum_{i=1}^{n_{triangles}} (p_{t_i^1} \times p_{t_i^2}) \cdot p_{t_i^3} \right) - k_{pressure} V_0 \tag{14}$$

刚度 $k = 1$。其中 $t_i^1, t_i^2, t_i^3$ 是第 $i$ 个三角形三个顶点的索引。求和计算封闭网格的实际体积，与原体积 $V_0$ 乘过压系数 $k_{pressure}$ 比较。该约束函数给出梯度

$$\nabla_{p_i} C = \sum_{j: t_j^1 = i} (p_{t_j^2} \times p_{t_j^3}) + \sum_{j: t_j^2 = i} (p_{t_j^3} \times p_{t_j^1}) + \sum_{j: t_j^3 = i} (p_{t_j^1} \times p_{t_j^2}) \tag{15}$$

这些梯度按式 (7) 的缩放因子缩放、按式 (9) 用质量加权，即得最终投影偏移 $\Delta p_i$。

## 5. 结果

我们已把方法集成进 Rocket [Rat04]——一个游戏风格的物理仿真环境。我们进行了多项实验来分析所提方法的特性与性能。本节所有测试场景都在 Pentium 4 3 GHz 的 PC 上运行。

**弯曲与拉伸独立。** 我们的弯曲项只依赖相邻三角形的二面角而非边长，因此弯曲与拉伸阻力可独立选取。图 3 展示一个布袋在不同拉伸刚度下、弯曲阻力先启用后禁用的情形。如上排所示，弯曲不影响拉伸阻力。

**双向交互的附着。** 我们可以模拟单向与双向耦合的附着约束。图 8 的布条顶部通过单向约束附着于静态刚体，底部与刚体启用双向交互。这一构型产生了视觉可信的布条摆动与扭转运动。该场景含 6 个刚体与 3 块布料，仿真与渲染合计超过 380 fps。

**实时自碰撞。** 图 6 的布料由 1364 个顶点、2562 个三角形组成，平均 30 fps 运行——包括自碰撞检测、碰撞处理与渲染。摩擦的效果见图 9：同一块布在旋转滚桶中翻滚。

**撕裂与稳定性。** 图 10 展示一块 4264 顶点、8262 三角形的布料，被附着的立方体撕开、再被投掷的球彻底撕碎。该场景平均 47 fps 仿真与渲染。撕裂由简单过程模拟：每当一条边的拉伸超过指定阈值，我们选择该边的一个相邻顶点，过该顶点作垂直于边方向的分裂平面并分裂顶点。分裂平面以上的三角形归属原顶点，以下的归属副本。即使极端情形下我们的方法仍保持稳定，如图 1（灵感来自 [ITF04]）：一个充气角色模型被挤压穿过旋转齿轮，多个约束、碰撞与自碰撞同时作用于单个布料顶点。

**复杂仿真场景。** 所提方法尤其适合复杂仿真环境（图 12）。尽管与动画角色、几何复杂的游戏关卡深度交互，多块布料的仿真与渲染仍能以交互速度完成。

## 6. 结论

我们提出了一个能处理经约束函数公式化的**一般约束**的基于位置的动力学框架。用位置基方法可以在仿真过程中直接操纵物体，这显著简化了碰撞、附着约束与显式积分的处理，并使动画场景的直接、即时控制成为可能。我们在此框架之上实现了一个鲁棒的布料模拟器，提供布料与刚体的双向交互、布料自碰撞与响应、以及布料与动态刚体的附着等功能。

## 7. 未来工作

本文未处理的一个主题是刚体仿真。但我们提出的方法可以相当容易地扩展到刚体：不再像常规刚体求解器那样为解决碰撞计算一组线性与角冲量，而是在接触点直接对物体施加移动与旋转，并在求解器完成后相应调整线速度与角速度（译注：这一方向后来由 Unified Particle Physics 2014 与 Fratarcangeli 2018 完成）。

## 附录 A：归一化叉积的梯度

约束函数常含归一化叉积。推导投影修正需要约束函数的梯度，因此了解归一化叉积对两个参数的梯度很有用。给定归一化叉积 $n = \frac{p_1 \times p_2}{|p_1 \times p_2|}$，对第一个向量的导数为

$$\frac{\partial n}{\partial p_1} = \frac{1}{|p_1 \times p_2|} \left( -\tilde{p}_2 + n (n \times p_2)^T \right) \tag{18}$$

$$\frac{\partial n}{\partial p_2} = -\frac{1}{|p_1 \times p_2|} \left( -\tilde{p}_1 + n (n \times p_1)^T \right) \tag{19}$$

其中 $\tilde{p}$ 是满足 $\tilde{p} x = p \times x$ 的矩阵。

**弯曲约束投影。** 弯曲的约束函数为 $C = \arccos(d) - \phi_0$，其中 $d = n_1 \cdot n_2 = n_1^T n_2$。不失一般性设 $p_1 = 0$，得法线 $n_1 = \frac{p_2 \times p_3}{|p_2 \times p_3|}$、$n_2 = \frac{p_2 \times p_4}{|p_2 \times p_4|}$。由 $\frac{d}{dx} \arccos(x) = -\frac{1}{\sqrt{1-x^2}}$ 得各梯度：

$$\nabla_{p_3} C = -\frac{1}{\sqrt{1-d^2}} \left( \frac{\partial n_1}{\partial p_3} \right)^T n_2 \tag{21}$$

$$\nabla_{p_4} C = -\frac{1}{\sqrt{1-d^2}} \left( \frac{\partial n_2}{\partial p_4} \right)^T n_1 \tag{22}$$

$$\nabla_{p_2} C = -\frac{1}{\sqrt{1-d^2}} \left( \left(\frac{\partial n_1}{\partial p_2}\right)^T n_2 + \left(\frac{\partial n_2}{\partial p_2}\right)^T n_1 \right) \tag{23}$$

$$\nabla_{p_1} C = -\nabla_{p_2} C - \nabla_{p_3} C - \nabla_{p_4} C \tag{24}$$

利用归一化叉积的梯度，先计算

$$q_3 = \frac{p_2 \times n_2 + (n_1 \times p_2) d}{|p_2 \times p_3|} \tag{25}$$

$$q_4 = \frac{p_2 \times n_1 + (n_2 \times p_2) d}{|p_2 \times p_4|} \tag{26}$$

$$q_2 = -\frac{p_3 \times n_2 + (n_1 \times p_3) d}{|p_2 \times p_3|} - \frac{p_4 \times n_1 + (n_2 \times p_4) d}{|p_2 \times p_4|} \tag{27}$$

$$q_1 = -q_2 - q_3 - q_4 \tag{28}$$

最终修正为

$$\Delta p_i = -\frac{w_i \sqrt{1-d^2}\, (\arccos(d) - \phi_0)}{\sum_j w_j |q_j|^2}\, q_i \tag{29}$$
