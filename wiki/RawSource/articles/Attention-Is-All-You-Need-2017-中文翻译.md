## 摘要

主流的序列转导模型基于复杂的循环或卷积神经网络，包含编码器与解码器。表现最好的模型还通过注意力机制把编码器与解码器连接起来。我们提出一种新的简洁网络架构——**Transformer**，完全基于注意力机制，彻底摒弃循环与卷积。在两个机器翻译任务上的实验表明：该模型在质量上更优，同时可并行性更强、所需训练时间显著更少。我们的模型在 WMT 2014 英德翻译上达到 **28.4 BLEU**，比已有最佳结果（含集成模型）高出 2 BLEU 以上。在 WMT 2014 英法翻译上，我们的模型在 8 块 GPU 上训练 3.5 天后取得 **41.8** 的单模型 SOTA BLEU，仅相当于文献中最好模型训练成本的一小部分。我们还将 Transformer 成功应用于英语成分句法分析（无论训练数据充足还是有限），表明其具有良好的泛化能力。

## 1 引言

循环神经网络——尤其是 LSTM `[13]` 与门控循环网络 `[7]`——在语言建模、机器翻译等序列建模与转导问题上已被牢固确立为当时的最先进方法 `[35, 2, 5]`。此后大量工作继续推进循环语言模型与编码器-解码器架构的边界 `[38, 24, 15]`。

循环模型通常沿输入/输出序列的符号位置来组织计算。把位置与计算时间步对齐，它生成一个隐状态序列 $h_t$，作为前一个隐状态 $h_{t-1}$ 与位置 $t$ 的输入的函数。这种固有的串行性质使得"训练样本内部无法并行"，在序列较长时尤为关键，因为显存约束限制了跨样本的批处理。近期工作通过分解技巧 `[21]` 与条件计算 `[32]` 在计算效率上取得显著改善（后者还提升了模型表现），但"顺序计算"这一根本约束依旧存在。

注意力机制已成为许多引人注目的序列建模与转导模型的核心组件，使模型能够建模依赖关系而不受其在输入/输出序列中距离的影响 `[2, 19]`。然而除少数例外 `[27]`，这些注意力机制通常与循环网络结合使用。

本工作中我们提出 Transformer——一种摒弃循环、完全依赖注意力机制来建立输入与输出间全局依赖的模型架构。Transformer 允许显著更高的并行化，在 8 块 P100 GPU 上仅训练约 12 小时即可达到翻译质量的新 SOTA。

## 2 背景

"减少顺序计算"这一目标也是 Extended Neural GPU `[16]`、ByteNet `[18]` 与 ConvS2S `[9]` 的基础——它们都用卷积神经网络作为基本构件，对所有输入输出位置并行计算隐表示。但在这些模型中，关联两个任意输入/输出位置所需的运算数随两位置距离增长——ConvS2S 线性增长，ByteNet 对数增长——这使远处依赖更难学习 `[12]`。在 Transformer 中，这被降到**常数级运算**；代价是由于"对注意力加权位置做平均"导致有效分辨率下降，我们用第 3.2 节的多头注意力来抵消这一效应。

> [!note] 多头注意力的根本动机
> 原文在此处给出了多头注意力最根本的动机陈述：**单头 attention 是"对所有位置做加权平均"，平均会模糊分辨率**；多头让模型在"不同表示子空间"里分别注意，恢复分辨率。这是 [[SelfAttention]] 里"不同头学不同关系"的**原因**，而非结果。

自注意力（有时称 intra-attention）是一种把单一序列中不同位置关联起来以计算该序列表示的注意力机制。它已成功用于阅读理解、抽象摘要、文本蕴含、任务无关的句子表示学习等任务 `[4, 27, 28, 22]`。

端到端记忆网络基于循环注意力而非"与序列对齐的循环"，在简单语言问答与语言建模上表现良好 `[34]`。

据我们所知，Transformer 是首个完全依赖自注意力来计算输入与输出表示、而不使用"与序列对齐的 RNN 或卷积"的转导模型。下面各节将描述 Transformer、论证自注意力、并讨论其相对于 `[17, 18]`、`[9]` 等模型的优势。

## 3 模型架构

大多数有竞争力的神经序列转导模型都采用编码器-解码器结构 `[5, 2, 35]`。编码器把输入符号表示序列 $(x_1, \dots, x_n)$ 映射为连续表示序列 $z = (z_1, \dots, z_n)$。给定 $z$，解码器再逐个生成输出符号序列 $(y_1, \dots, y_m)$，每步一次。每一步模型是**自回归**的 `[10]`：生成下一个符号时，把此前已生成的符号作为额外输入。

Transformer 遵循这一总体架构，编码器与解码器分别用堆叠的自注意力层与逐位置的全连接层构成（对应图 1 的左右两半）。

### 3.1 编码器与解码器堆叠

**编码器**：由 $N = 6$ 个相同层堆叠而成。每层有两个子层——第一是多头自注意力机制，第二是简单的逐位置全连接前馈网络。每个子层外绕残差连接 `[11]`，后接层归一化 `[1]`。即每个子层输出为

$$\text{LayerNorm}(x + \text{Sublayer}(x))$$

其中 $\text{Sublayer}(x)$ 是该子层自身实现的函数。为便于残差连接，模型所有子层及 embedding 层的输出维度都是 $d_{\text{model}} = 512$。

> [!note] 原版用 post-norm
> 原版是 **post-norm**：归一化在残差相加**之后**。补间论文（你的 [[Transformer]] / [[TrainingMechanics]] 所本）改用 **pre-norm**：$x + \text{Sublayer}(\text{LayerNorm}(x))$，残差流干净直通、深网更稳。你的 Wiki 结构图是 pre-norm，读原版时需校准此处。

**解码器**：同样由 $N = 6$ 个相同层堆叠。除编码器每层的两个子层外，解码器还插入第三个子层，对编码器堆叠的输出做多注意力。与编码器一样，每个子层外绕残差连接后接层归一化。我们还修改了解码器中的自注意力子层，使其不能关注后续位置。这种**掩码**，加上输出 embedding 右移一位的事实，保证位置 $i$ 的预测只能依赖小于 $i$ 的已知输出。

### 3.2 注意力

注意力函数可描述为：把一个**查询**（query）与一组**键值对**（key-value pairs）映射到一个输出，其中 query、keys、values、output 都是向量。输出是 values 的加权和，每个 value 的权重由 query 与对应 key 的兼容函数计算得到。

#### 3.2.1 缩放点积注意力

我们称自己的注意力为"缩放点积注意力"（图 2 左）。输入为维度 $d_k$ 的 query 与 key、维度 $d_v$ 的 value。计算 query 与所有 key 的点积，每个除以 $\sqrt{d_k}$，再经 softmax 得到 value 上的权重。

实践中我们同时处理一批 query（打包成矩阵 $Q$），key 与 value 也分别打包成 $K$ 与 $V$。输出矩阵为：

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V \tag{1}$$

两种最常用的注意力函数是**加性注意力** `[2]` 与**点积（乘性）注意力**。点积注意力与本文算法除缩放因子 $1/\sqrt{d_k}$ 外完全相同。加性注意力用单隐层前馈网络计算兼容函数。两者理论复杂度相近，但点积注意力在实践中快得多、更省空间，因为可用高度优化的矩阵乘法实现。

当 $d_k$ 较小时两者表现相近；不加缩放时，$d_k$ 较大时加性注意力优于点积注意力 `[3]`。我们怀疑：$d_k$ 大时点积数值幅度变大，把 softmax 推入梯度极小的区域。为抵消此效应，我们用 $1/\sqrt{d_k}$ 缩放点积。

> [!info] 脚注 4：点积为何变大
> 设 $q$、$k$ 各分量为均值 $0$、方差 $1$ 的独立随机变量，则 $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的均值为 $0$、方差为 $d_k$。即点积标准差随 $\sqrt{d_k}$ 增长，$d_k$ 大时 softmax 饱和、梯度近 0。除以 $\sqrt{d_k}$ 把方差拉回 1。详见 [[SelfAttention]]。

#### 3.2.2 多头注意力

与其用 $d_{\text{model}}$ 维的 key/value/query 做单次注意力，我们发现把 query、key、value 各用不同的、学到的线性投影 $h$ 次投影到 $d_k$、$d_k$、$d_v$ 维更为有益。对每一组投影后的 query/key/value 并行执行注意力，得到 $d_v$ 维输出；把这些拼接后再做一次投影，得到最终值（图 2 右）。

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h)\, W^O$$

$$\text{where } \text{head}_i = \text{Attention}(Q W_i^Q,\; K W_i^K,\; V W_i^V)$$

投影参数矩阵：$W_i^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$，$W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$，$W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$，$W^O \in \mathbb{R}^{h d_v \times d_{\text{model}}}$。

本工作用 $h = 8$ 个并行注意力头。每个头 $d_k = d_v = d_{\text{model}}/h = 64$。由于每头维度降低，**总计算量与"全维度单头注意力"相近**。

多头注意力让模型能"在不同位置、从不同表示子空间"联合关注信息。单头因平均而抑制了这一点。

#### 3.2.3 注意力在本模型中的三种用法

Transformer 以三种方式使用多头注意力：

1. **编码器-解码器注意力层**：query 来自上一层解码器，memory 的 key/value 来自编码器输出。这使解码器每个位置都能关注输入序列的所有位置，模仿 `[38, 2, 9]` 中典型的编码器-解码器注意力。
2. **编码器自注意力层**：所有 key、value、query 来自同一处——编码器上一层输出。编码器每个位置可关注上一层所有位置。
3. **解码器自注意力层**：允许解码器每个位置关注解码器中直到并包括该位置的所有位置。为保持自回归性，需阻止解码器中"向左"的信息流。实现方式是在 softmax 输入中把对应非法连接的位置置为 $-\infty$（见图 2）。

> [!note] 补间论文是 Encoder-only
> 原版是**编码器-解码器**（自回归翻译），三种注意力都用。补间论文改用 **Encoder-only + mask**（BERT 式完形填空），只有第三种变体（带 mask 的 self-attention），没有 encoder-decoder attention。详见 [[Transformer]] §三种用法。

### 3.3 逐位置前馈网络

除注意力子层外，编码器与解码器每层还含一个全连接前馈网络，对每个位置独立且相同地施加。由两次线性变换与中间的 ReLU 组成：

$$\text{FFN}(x) = \max(0,\; xW_1 + b_1)\, W_2 + b_2 \tag{2}$$

不同位置用相同的线性变换，但不同层之间用不同参数。等价说法：这是**两个核大小为 1 的卷积**。输入输出维度 $d_{\text{model}} = 512$，内层维度 $d_{ff} = 2048$。

### 3.4 Embedding 与 Softmax

与其他序列转导模型类似，用学到的 embedding 把输入/输出 token 转为 $d_{\text{model}}$ 维向量；用通常的学到的线性变换 + softmax 把解码器输出转为下一 token 的预测概率。本模型中，**两个 embedding 层与 pre-softmax 线性变换共享同一权重矩阵**（类似 `[30]`）。在 embedding 层中，把这些权重乘以 $\sqrt{d_{\text{model}}}$。

> [!info] 为什么 embedding 乘 √d_model
> 接下来要加位置编码（正弦 PE 幅值在 $[-1, 1]$），而学出来的 embedding 若量级太小会被 PE 淹没；乘 $\sqrt{d_{\text{model}}} \approx 22.6$ 把 embedding 抬到和 PE 可比的尺度。这是个常被忽略的工程细节。

### 3.5 位置编码

由于模型既无循环也无卷积，为利用序列顺序，必须注入关于序列中 token 相对或绝对位置的信息。为此在编码器与解码器堆叠底部的输入 embedding 上加"位置编码"。位置编码维度与 embedding 相同（$d_{\text{model}}$），二者可直接相加。位置编码有学习与固定等多种选择 `[9]`。

本工作用不同频率的正弦与余弦函数：

$$PE_{(pos,\, 2i)} = \sin\!\left(pos / 10000^{2i/d_{\text{model}}}\right)$$

$$PE_{(pos,\, 2i+1)} = \cos\!\left(pos / 10000^{2i/d_{\text{model}}}\right)$$

其中 $pos$ 是位置，$i$ 是维度。即位置编码的每一维对应一个正弦波。波长从 $2\pi$ 到 $10000 \cdot 2\pi$ 构成几何级数。选择此函数是因为我们假设它能让模型容易学到"按相对位置注意"：对任意固定偏移 $k$，$PE_{pos+k}$ 可表示为 $PE_{pos}$ 的**线性函数**。

我们也实验过用学到的位置 embedding `[9]` 替代，发现两者结果几乎相同（见表 3 行 E）。选正弦版本是因其可能允许模型**外推到比训练中遇到的更长的序列长度**。

> [!note] 补间论文改用学到的 PE
> 补间论文不走正弦这条路，而是直接学 Relative PE（[[InbetweeningPositionalEncodings]]），因为动画里"相对帧距"比"绝对词位置"重要得多，且要泛化到超长序列——直接参数化相对位置更省事。原版的正弦编码能外推，但表达不出"距关键帧"这种结构化位置。

## 4 为何用自注意力

本节把自注意力层与"常用于把变长符号序列 $(x_1, \dots, x_n)$ 映射为等长序列 $(z_1, \dots, z_n)$（$x_i, z_i \in \mathbb{R}^d$）"的循环层与卷积层作比较——例如典型序列转导编码器/解码器中的隐层。我们用**三条标准**来论证自注意力：

1. 每层总计算复杂度；
2. 可并行的计算量（用"最少顺序操作数"衡量）；
3. 网络中长程依赖的路径长度。

学习长程依赖是许多序列转导任务的关键挑战。影响此能力的一个关键因素是前向与反向信号在网络中需穿越的路径长度。任意输入输出位置对之间路径越短，越易学长程依赖 `[12]`。

如表 1 所示，自注意力层以常数级顺序操作连接所有位置，而循环层需 $O(n)$ 顺序操作。计算复杂度方面，当序列长度 $n$ 小于表示维度 $d$ 时，自注意力比循环快——这在机器翻译 SOTA 模型使用的 word-piece `[38]`、BPE `[31]` 等句子表示中通常是成立的。为提升超长序列任务的效率，自注意力可被限制为只考虑以输出位置为中心、半径 $r$ 的邻域，这会把最大路径长度增到 $O(n/r)$，我们计划进一步研究。

单层核宽 $k < n$ 的卷积无法连接所有输入输出对。要做全连接，连续核需 $O(n/k)$ 层卷积，膨胀卷积需 $O(\log_k n)$ 层 `[18]`——增加了任意两位置间最长路径。卷积层通常比循环层贵 $k$ 倍。但可分离卷积 `[6]` 显著降低复杂度到 $O(k \cdot n \cdot d + n \cdot d^2)$。即便 $k = n$，可分离卷积的复杂度也等于"自注意力层 + 逐位置前馈层"的组合——正是我们模型的做法。

作为附带收益，自注意力可产生更可解释的模型。我们在附录中检视模型的注意力分布并讨论示例。许多注意力头不仅明显学到不同任务，还表现出与句子句法语义结构相关的行为。

**表 1：不同层类型的最大路径长度、每层复杂度与最少顺序操作数。**
（$n$ = 序列长度，$d$ = 表示维度，$k$ = 卷积核大小，$r$ = 受限自注意力的邻域大小。）

| 层类型 | 每层复杂度 | 顺序操作 | 最大路径长度 |
|---|---|---|---|
| Self-Attention | $O(n^2 \cdot d)$ | $O(1)$ | $O(1)$ |
| Recurrent | $O(n \cdot d^2)$ | $O(n)$ | $O(n)$ |
| Convolutional | $O(k \cdot n \cdot d^2)$ | $O(1)$ | $O(\log_k n)$ |
| Self-Attention（受限） | $O(r \cdot n \cdot d)$ | $O(1)$ | $O(n/r)$ |

## 5 训练

本节描述模型的训练设定。

### 5.1 训练数据与批处理

英德用标准 WMT 2014 数据集，约 **450 万**句对，BPE 编码 `[3]`，共享源-目标词表约 **37000** token。英法用更大的 WMT 2014 数据集，**3600 万**句，word-piece 词表 **32000** `[38]`。按近似序列长度分桶批处理，每批约含 25000 源 token 与 25000 目标 token。

### 5.2 硬件与时间表

单机 8 块 NVIDIA P100 GPU。base 模型每步约 0.4 秒，共训 100,000 步（12 小时）。big 模型每步 1.0 秒，训 300,000 步（3.5 天）。

### 5.3 优化器

Adam 优化器 `[20]`，$\beta_1 = 0.9$，$\beta_2 = 0.98$，$\epsilon = 10^{-9}$。学习率随训练步数变化：

$$\text{lrate} = d_{\text{model}}^{-0.5} \cdot \min\!\left(\text{step}^{-0.5},\; \text{step} \cdot \text{warmup}^{-1.5}\right) \tag{3}$$

即前 `warmup_steps` 步线性上升，之后按步数平方根倒数衰减。`warmup_steps = 4000`。

> [!note] β₂=0.98 是非默认值
> Adam 默认 $\beta_2 = 0.999$，原版改成 **0.98**——二阶矩滑窗更短、响应更快。补间论文用 $0.999$ + warmup 8000（见 [[TrainingMechanics]]）。两个改动都有道理：pre-norm + 更深特征需更慢 warmup 让 $v_t$ 估稳；$\beta_2$ 一激进一保守。这是原版 vs 补间的真实调参分歧。

### 5.4 正则化

训练中用三种正则化：

1. **残差 Dropout**：对每个子层输出、在"加到子层输入并归一化之前"施加 dropout `[33]`。此外对 embedding 与位置编码之和也施加 dropout。base 模型 $P_{\text{drop}} = 0.1$。
2. **Label Smoothing**：训练中用 $\ell_s = 0.1$ 的标签平滑 `[36]`。这会**损害困惑度**（模型变得更不确定），但**提升准确率与 BLEU**。

## 6 结果

### 6.1 机器翻译

WMT 2014 英德：big 模型（表 2）比此前最佳模型（含集成）高 2.0 BLEU 以上，新 SOTA **28.4 BLEU**，8 块 P100 训练 3.5 天。即便 base 模型也超过此前所有已发表模型与集成，且训练成本远低于任何有竞争力的模型。

WMT 2014 英法：big 模型 BLEU **41.8**，超过此前所有单模型，训练成本不到此前 SOTA 的 1/4。英法 big 模型用 $P_{\text{drop}} = 0.1$（而非 0.3）。

base 模型用"最后 5 个 checkpoint（每 10 分钟存一次）平均"得到；big 模型用最后 20 个 checkpoint 平均。beam search beam=4，长度惩罚 $\alpha = 0.6$ `[38]`。推理时最大输出长度设为"输入长度 + 50"，并在可能时提前终止 `[38]`。

> [!info] 训练成本估计方法
> FLOPs 估计 = 训练时间 × GPU 数 × 每块 GPU 持续单精度浮点能力；K80/K40/M40/P100 分别取 2.8/3.7/6.0/9.5 TFLOPS。

## 7 结论

本工作提出 Transformer——首个完全基于注意力的序列转导模型，用多头自注意力替换编码器-解码器架构中最常用的循环层。

对翻译任务，Transformer 可比基于循环或卷积的架构显著更快地训练。在 WMT 2014 英德与英法翻译任务上均达到新 SOTA；前者甚至超过所有已报告的集成模型。

我们对基于注意力的模型的未来感到兴奋，计划将其应用于文本以外的输入输出模态，并研究局部受限的注意力机制以高效处理图像、音频、视频等大输入输出。让生成过程更少顺序化也是研究目标之一。

> [!note] 预言性极强
> 这一段写于 2017 年——Vision Transformer（图像）、audio transformer、Longformer/稀疏注意力（restricted）、non-autoregressive generation（less sequential），后来整整六年的大研究线全在这一句里。
