# 体检规则

## 检查项严重等级

| 检查项 | 默认等级 | 说明 |
|--------|---------|------|
| 矛盾检测 | 🔴 高 | 立即处理，避免误导 |
| 过时内容 | 🟡 中 | 下次录入时同步更新 |
| 孤儿页面 | 🟡 中 | 考虑添加引用或删除 |
| 缺失概念页 | 🟠 中高 | 优先补充高频引用的概念 |
| 缺失交叉引用 | 🟢 低 | 批量处理，不紧急 |
| Summary 字段质量 | 🟠 中高 | 直接影响 Query L1 检索效率与 token 成本 |
| OpenViking 向量索引同步 | 🟠 中高 | 漏/脏索引会导致 L1.5/L3 语义检索失效或污染 |

> **OV 关闭时（local 模式）**：跳过第 7 项（向量索引同步），仅执行前 6 项。

## 体检频率建议

- 常规录入：每 10 次 Ingest 后执行一次
- 重大重构后：立即执行
- 定期维护：每月一次

## 孤儿页面处理策略

- 有价值但无引用 → 在最相关的 entity 页面添加"参见"链接
- 内容已过时 → 删除或合并到更新页面
- 内容重复 → 合并到主页面，添加重定向说明
