# 神经网络基础（DNN 与 MLP）

## 最小单元：一个神经元

```
y = φ(W·x + b)
```

- `x`：输入向量
- `W`：权重矩阵（要学的参数）
- `b`：偏置（要学的参数）
- `φ`：非线性激活函数（ReLU、PReLU、sigmoid 等）

**`φ` 不能省。** 没有 `φ`，`W·x+b` 是纯线性运算，而线性的复合仍是线性——叠 100 层线性层等价于一个线性层，深度毫无意义。**非线性是深度产生的根本原因。**

## 一层与"深度"

一层 = 很多神经元并行：`h = φ(W·x + b)`，把输入维 `d_in` 映射到隐藏维 `d_model`（如 135→512）。输出 `h` 称**特征表示**。

深度 = 把很多层串起来：

```
x → 第1层 → h1 → 第2层 → h2 → ... → 第L层 → y
```

深度的力量在**层级特征组合**：早期层学简单模式（"这帧在不在地上"），后期层组合成复杂概念（"这是一个转身过渡"）。

## 训练 = 找好的 W 和 b

1. 初始化：所有 `W`、`b` 随机赋值
2. 前向：喂样本，算输出 `y`
3. 算损失：衡量 `y` 与目标差多远（L1/L2 等）
4. 反向传播：倒推每个参数对误差负多少责任（梯度），见 [[Backpropagation]]
5. 更新：按梯度反方向微调（梯度下降 / [[TrainingMechanics|Adam]]）
6. 重复几十万至几百万次

**"训练好的模型"就是一堆调好的 `W`、`b` 数值。** 推理时固定不变，前向跑一次出结果。

## MLP（多层感知机）

MLP 是最简单的那种深度网络：若干"线性层 + 非线性激活"串联，每层**全连接**。也叫 feedforward network。

```
x (d_in)
 │ Linear: W1·x+b1  → 激活 φ
 ▼
h1 (d_h)
 │ Linear: W2·h1+b2 → 激活 φ
 ▼
h2 (d_h)
 │ Linear: W3·h2+b3
 ▼
o (d_out)
```

### "全连接"的含义

下一层每个神经元都连到上一层每个输入。6 维输入 → 4 维隐藏层，则 `W1` 是 **4×6 矩阵**：4 个隐藏神经元各"看"全部 6 个输入。

**参数量**：一层 `(d_in → d_out)` 参数 = `d_in × d_out + d_out`。这就是全连接参数多的原因——连接数按乘法增长。

> 论文 encoder 是 `135→512→512`，参数 ≈ `135×512+512 + 512×512+512 ≈ 33 万`。

### 为什么普遍是 2 层

投影/编解码 MLP 普遍用**一隐层（2 个 W）**：

- **1 个 W**：只有一次非线性变换，表达力偏弱
- **2 个 W**：经典单隐层 MLP，最小的万能逼近器结构，够用来学一个好投影
- **更多 W**：参数膨胀、难训、对"投影"这种任务收益递减

decoder 镜像也是 2 个 W，但**最后一层后不加激活**——输出是数值（可正可负），不该被激活压扁。

### 能力与局限

**能做**：万能逼近定理保证，足够宽/深的 MLP 能逼近任何连续函数。

**不能做**（关键局限）：

1. **没有结构感**：把 135 维当无序向量，不知道"这 6 个数是一个关节的旋转"
2. **没有时序感**：处理 30 帧只能把 `30×135=4050` 拍扁喂入 → 参数爆炸、换成 45 帧就喂不进（无法变长）、丢失顺序信息
3. 因此 **MLP 单独处理序列很糟糕**——这正是 [[RecurrentNetworks|RNN]] 和 [[Transformer]] 被发明的原因

### 关键性质：逐帧独立 + 权重共享

这是理解 Transformer 的钥匙。MLP 处理序列时的用法：

```
帧0 ──MLP──► 帧0'
帧1 ──MLP──► 帧1'    ← 同一套 W、b，可并行
帧2 ──MLP──► 帧2'
```

**MLP 不混合帧与帧**，只对每帧内部特征做变换。混合帧是 [[SelfAttention|注意力]]的事。Transformer 里的 [[Transformer|FFN]] 就是这么用的——所以叫 "position-wise"（逐位置的）FFN。

## PReLU

论文全用 PReLU 激活：

```
ReLU:      y = max(0, x)        ← 负数归零（梯度为 0，"死神经元"）
LeakyReLU: y = max(0.01x, x)    ← 负数乘固定小系数
PReLU:     y = max(α·x, x)      ← α 可学（每通道一个）
```

PReLU 让负区有**可学习斜率**，比 ReLU 柔和、不易死。

## 术语陷阱：FCN ≠ MLP

论文 Table 1 的 **FCN baseline 是 Fully-Convolutional Network（全卷积网络）**，用 Conv1d，不是 MLP。"全连接（fully-connected）"与"全卷积（fully-convolutional）"都带 F，易混。MLP ≈ 全连接网络；论文的 FCN 是卷积网络。

## 在本项目中的体现

MLP 是 [[ContextTransformer]] / [[DetailTransformer]] 里的基础砖块，出现在：encoder（136→512→512）、decoder（512→512→135/139）、每层 FFN（512→512→512）、Keyframe PE 生成器（2→512→512）、相对 PE 生成器（1→64→64）。

**[[Transformer]] = MLP（逐帧变换）+ [[SelfAttention]]（跨帧混合）**。MLP 是砖，注意力是把砖跨帧连起来的水泥。
