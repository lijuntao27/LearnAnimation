# 训练机制（损失函数 / 梯度消失 / LayerNorm / Adam）

本页收集让深网（尤其是 [[Transformer]]）能稳定训练的机制，四块基石：**交叉熵代价**（绕过神经元饱和，让误差信号不被掐死）、**梯度消失/爆炸**（反向传播连乘的必然结果，及其解法）、**LayerNorm**（压住数值幅度）与 **Adam**（稳健的优化器）。

---

## 神经元饱和与交叉熵代价

> 来源：Nielsen《Neural Networks and Deep Learning》Ch.3 前半。回答的问题是"为什么不用最朴素的 MSE 而用交叉熵"。

### 什么是神经元饱和

Sigmoid 输出 $a=\sigma(z)=\frac{1}{1+e^{-z}}$ 在 $z$ 很正/很负时，输出被"钉"在 1/0 两端，曲线几乎躺平：

- $z$ 很大正 → $a\approx1$（高端饱和）；$z$ 很负 → $a\approx0$（低端饱和）
- 定量含义：$\sigma'(z)=\sigma(z)(1-\sigma(z))$ 在两端趋近 0

**饱和 = 输出对输入变化不敏感 = 导数 $\sigma'$ 趋近 0。**

### 饱和如何"杀死"学习

权重更新靠梯度 $w\to w-\eta\,\partial C/\partial w$。二次代价（MSE）下单个神经元的梯度是：

$$
\frac{\partial C}{\partial w}=(a-y)\,\sigma'(z)\,x
$$

右边混着 $\sigma'(z)$：一旦神经元饱和，$\sigma'\approx0$，**梯度被掐灭，权重几乎不动**。于是出现反直觉现象——神经元错得越离谱（$a$ 远离 $y$，恰好掉进饱和区）反而学得越慢。

> Nielsen Ch.3 的玩具实验：单神经元学"输入 1 → 输出 0"，起始 $w=b=2.0$ 时初始输出 $a\approx0.98$（错得离谱、且高端饱和），前 ~150 回合权重几乎不变，直到训练把 $z$ 拉回陡峭区学习才启动。

### 交叉熵怎么救：把 σ′ 项约掉

交叉熵 $C=-(y\ln a+(1-y)\ln(1-a))$ 对权重求导时，链式法则先产生 $\sigma'$，但分子分母恰好约分：

$$
\frac{\partial C}{\partial w_j}
=-\Big(\frac{y}{\sigma}-\frac{1-y}{1-\sigma}\Big)\sigma'\,x_j
=\frac{\sigma'\,x_j}{\sigma(1-\sigma)}\,(\sigma-y)
=x_j\,(a-y)
$$

关键恒等式 $\sigma'=\sigma(1-\sigma)$ 让 $\sigma'$ **自我抵消**，梯度只剩纯误差：

$$
\frac{\partial C}{\partial w_j}=x_j(a-y),\qquad
\frac{\partial C}{\partial b}=(a-y)
$$

**误差越大梯度越大、学得越快**——恢复人类直觉，饱和区不再是学习黑洞。

### 用反向传播视角看：它只解决了输出层

| 方程 | 含 $\sigma'$ 的位置 | 交叉熵的作用 |
|---|---|---|
| BP1 $\delta^L=(a^L-y)\odot\sigma'(z^L)$ | 输出层 | ✅ 交叉熵让 $\delta^L$ 变成干净的 $a-y$ |
| BP2 $\delta^l=((w^{l+1})^T\delta^{l+1})\odot\sigma'(z^l)$ | **每一层** | ❌ 隐藏层的 $\sigma'$ 还在 |

交叉熵让误差从输出层出发时就"满血"，但**隐藏层饱和（BP2 的 $\sigma'$）仍需另想办法**——换激活函数（ReLU 正区间 $\sigma'=1$ 不饱和）是 Ch.5 梯度消失的主角。

### 三条解决路线 + 适用边界

| 方案 | 做法 | 解决哪里的饱和 |
|---|---|---|
| **交叉熵代价** | 让 $\sigma'$ 在输出层求导时约掉 | 输出层（BP1） |
| **softmax + 对数似然** $C=-\ln a_y$ | 输出层误差同样是干净的 $a-y$ | 输出层（等价方案） |
| **换激活函数**（ReLU 等） | 正区间 $\sigma'=1$ 不饱和 | 隐藏层（BP2） |

**适用边界**：
- 交叉熵要求 $y,a\in[0,1]$；$a\in(0,1)$ 由 sigmoid/softmax **结构保证**，$y$ 需是 0/1（one-hot 分类）才成立
- 交叉熵只在 $y\in\{0,1\}$ 时能随 $a\to y$ 归零；软标签（$0<y<1$）时损失下界是二元熵 $H(y)=-[y\ln y+(1-y)\ln(1-y)]$，到不了 0
- 输出层若是线性神经元（$a^L=z^L$，无 $\sigma$），二次代价也不含 $\sigma'$、无饱和问题——饱和是 sigmoid 特有的，要么抵消、要么不用 sigmoid

> 一句话：**饱和 = sigmoid 两端 $\sigma'\to0$，把误差信号掐死；交叉熵利用 $\sigma'=\sigma(1-\sigma)$ 让 $\sigma'$ 在求导时自我抵消，梯度只剩误差 $a-y$。** 它解决输出层饱和，隐藏层饱和留给换激活函数（见 [[Backpropagation]] 的 BP2 与 ReLU 讨论）。

## Softmax + 对数似然：交叉熵的姐妹方案

交叉熵解决饱和的另一条等价路线是换**输出层结构**（而非只换代价）：用 softmax 层配**对数似然（log-likelihood）代价**。Nielsen Ch.3 明确说两者"颇为相似"（softmax+对数似然 ≈ sigmoid+交叉熵），本书到 Ch.6 会用。

### Softmax 输出层

定义：softmax 层先算加权输入 $z^L_j$，但不用 sigmoid，而是：

$$
a^L_j = \frac{e^{z^L_j}}{\sum_k e^{z^L_k}}
$$

两个性质让它输出天然是**概率分布**：
- **全正**：指数函数保证 $a^L_j>0$
- **和为 1**：$\sum_j a^L_j=\frac{\sum_j e^{z^L_j}}{\sum_k e^{z^L_k}}=1$

于是可把 $a^L_j$ 解释为"网络对正确类别是 $j$ 的估计概率"——这是 sigmoid 输出层给不了的（sigmoid 各输出独立，加起来≠1）。

> 概念细节（单调性、非局域性、温度/缩放、mask 的 $-\infty$ 技巧）见 [[NeuralNetworkBasics]] 的 Softmax 节与 [[SelfAttention]]。这里只讲训练维度。

### 对数似然代价：只罚"正确类别"那一项

$$
C \equiv -\ln a^L_y
$$

其中 $a^L_y$ 是**真实类别 $y$ 对应的那个输出神经元**的激活（MNIST 输入 7 时就是 $a^L_7$）。

直觉：网络越确信正确类别（$a^L_y\to1$）代价越小；越不确信（$a^L_y\to0$）代价越大（$-\ln a\to\infty$）。它不显式管错误类别的输出——但 softmax 的"和为 1"约束自动让错误类别被压低（一个涨、其余必降）。

### 为何它也解决饱和：同样的干净误差

反向传播过这一层，输出误差同样是：

$$
\delta^L_j = a^L_j - y_j
$$

（$y_j$ 是 one-hot 目标向量，正确位为 1。）**与交叉熵的 $\delta^L=a^L-y$ 完全同形**——没有 $\sigma'$ 项，饱和不掐误差。代价对权重偏置的梯度因此是：

$$
\frac{\partial C}{\partial b^L_j}=a^L_j-y_j,\qquad
\frac{\partial C}{\partial w^L_{jk}}=a^{L-1}_k(a^L_j-y_j)
$$

与交叉熵的式 (67) 逐字相同，只是 $y$ 换成了 one-hot 向量。

### 两条路线对照

| | sigmoid + 交叉熵 | softmax + 对数似然 |
|---|---|---|
| 输出结构 | 各神经元独立 sigmoid | 整层 softmax，输出成概率分布 |
| 代价 | $-\sum_j[y_j\ln a_j+(1-y_j)\ln(1-a_j)]$ | $-\ln a_y$ |
| 输出层误差 $\delta^L$ | $a^L-y$ | $a^L-y$ |
| "概率分布"解释 | 每神经元是二元分布 $\{a,1-a\}$ | 整层是一个多项分布 |
| 何时用 | 多标签/二分类（输出独立） | 多分类、想直接读概率（Nielsen Ch.6） |

> 关键点：**两者殊途同归——都让输出层误差 $\delta^L$ 变成干净的 $a-y$，没有 $\sigma'$。** 差别只在于"概率"体现在哪：交叉熵把每个 sigmoid 神经元看成二元分布，softmax 把整层看成一个分布。用哪个主要看你想不想让输出直接可解释为概率（多分类选 softmax+对数似然）。

## 梯度消失与梯度爆炸

> 来源：Nielsen《Neural Networks and Deep Learning》Ch.5。上面"饱和"是**单神经元**的局部现象，本节是它在**深网**里的整体爆发——两者同源（都是 $\sigma'$ 在作祟），只是尺度不同。回答：深网为什么难训？何时消失、何时爆炸？

### 本质：反向传播 = 一路连乘

误差从输出层往输入层走，**每穿过一层就乘一组因子**。以每层单神经元的链为例，第 1 层偏置的梯度是：

$$
\frac{\partial C}{\partial b_1}=\underbrace{w_2\sigma'(z_2)}_{第2层}\cdot\underbrace{w_3\sigma'(z_3)}_{第3层}\cdot\underbrace{w_4\sigma'(z_4)}_{第4层}\cdot\frac{\partial C}{\partial a_4}
$$

**越靠前的层，乘积里因子越多。** 前层梯度 = 一串数的连乘——这串数长什么样，决定梯度变小还是变大。连乘像复利：每层缩水 4 倍，10 层后 $\approx10^{-6}$；每层放大 25 倍，10 层后天文数字。

### 每个因子多大？两个事实定生死

每个因子是"权重 × 激活斜率"两项之积 $w\sigma'(z)$：

1. **sigmoid 导数最大只有 1/4**：$\sigma'(z)=\sigma(z)(1-\sigma(z))\le\sigma'(0)=\frac14$（$z=0$ 处峰值，两端趋 0 = 饱和区）
2. **常规初始化权重通常 $|w|<1$**（均值 0、标准差 1 的高斯）

合起来：**$|w\sigma'(z)|<0.25$**，典型还更小。

### 梯度消失：因子 <1，越乘越薄

每层因子约 0.25 时，梯度反传 3 层：

| 梯度 | 乘的因子数 | 相对大小 |
|---|---|---|
| 输出层 | 0 | $1$ |
| 第 2 层 | 1 | $0.25$ |
| 第 1 层 | 2 | $0.25^2\approx0.06$ |

深到 10 层：第 1 层 $\propto0.25^9\approx4\times10^{-6}$，比输出层小百万倍。梯度是更新信号 $w\leftarrow w-\eta\frac{\partial C}{\partial w}$，前层梯度 $\approx0$ → **前层权重几乎不动、根本学不到**。Ch.5 实证：`[784,30,30,30,30,10]` 网络第一隐藏层学习速度比最后一层慢约 **100 倍**。

> **梯度消失 = 连乘把梯度稀释到接近 0，前层停止学习。** 症状：加更多层，网络反而不如浅层（浅层前层至少还在学，深层前层直接躺平）。

### 梯度爆炸：因子 >1，越乘越猛

因子若 >1，每反传一层放大一次，到前层变天文数字：

> **梯度爆炸 = 连乘把梯度放大到巨大，权重更新失控。** 症状：损失 NaN / 剧烈震荡。

要让因子 >1，因 $\sigma'\le0.25$，必须 $|w|>4$。Ch.5 人为构造：$w=100$ 且 bias 调成 $z_j=0$（$\sigma'$ 取到最大 0.25）→ 每层因子 $100\times0.25=25$，3 个隐藏层反传到第 1 层即 $25^3=15625$ 倍。

### 何时出现：判据 + 现实

> **每层因子 $|w\sigma'(z)|$ 平均 <1 → 消失；平均 >1 → 爆炸。**

| 情形 | 因子大小 | 结果 |
|---|---|---|
| sigmoid + 常规初始化 + 深度 | $\le0.25$（几乎总 <1） | **消失（最常见）** |
| 大权重（$\|w\|\ge4$）+ 激活不饱和 | $>1$ | 爆炸 |
| sigmoid + 极大权重但饱和 | $\sigma'\to0$ | 又变消失 |

**为何实践中几乎总是"消失"而非"爆炸"？** $\sigma'(z)=\sigma'(wa+b)$ 也依赖 $w$：把 $w$ 调大想使因子 >1 时，$wa+b$ 变大、把 $z$ 推进 sigmoid 饱和区（$\sigma'$ 趋 0）——两效果打架。要 $|w\sigma'(z)|\ge1$ 需 $|w|\ge4$ **且**输入激活落在很窄区间（Ch.5 算过：最宽约 0.45）。所以：普通初始化 + sigmoid → 几乎必然**消失**；爆炸需刻意大权重 + 恰好不饱和，是"事故"而非常态（RNN 里偶见）。

> **深层网络 + 朴素梯度法 = 梯度不稳定**——不是消失就是爆炸，这是 Ch.5 的结论，也是"深度网络难训"的根本原因。

### 与饱和的关系 + 解法对照

饱和是单神经元的"局部病灶"，梯度消失是它在深网的"系统性爆发"——都源于 $\sigma'$。解法本质都是**控制因子大小**：

| 手段 | 作用 | 出处 |
|---|---|---|
| 交叉熵 / softmax+对数似然 | 消掉**输出层** $\sigma'$（$\delta^L=a-y$） | 本页上文 |
| **换 ReLU** | 正区间 $\sigma'=1$（不是 0.25）→ 因子从 $\le0.25$ 提到 $w$ | Ch.3 末 / Ch.6 |
| 精心初始化（$1/\sqrt{n_{in}}$） | 权重初始在 1 附近，别把 $z$ 推进饱和区 | Ch.3 |
| **LayerNorm**（下节） | 把每层输入拉回 0 附近，避开 $\sigma'$ 趋 0 的翼部 | 本页下节 |
| 卷积层共享权重 | 大幅减少参数，缓解连乘病态 | Ch.6 |

> 一句话：**梯度消失/爆炸是"反向传播 = 链式连乘"的必然结果——每层因子 $\approx w\sigma'(z)$，都 <1 就消失、都 >1 就爆炸；sigmoid 的 $\sigma'$ 最大 1/4，所以常规深度网络几乎总是消失（前层学不动）。要避免就得把因子控制在 1 附近：换 ReLU（斜率=1）+ 好初始化 + 归一化。**

## LayerNorm：压住深网里数值"失控"

### 解决什么问题

一个 6 层 Transformer，数据要连过 12 个子层（每层 attention + FFN）。每过一次特征值就被矩阵乘、非线性变换。问题：**各维度的数值幅度会越走越分叉**——有的维度爆炸到几千，有的缩到零点零零几。

幅度失衡带来两个灾难：

- **梯度失衡**：大幅度的维度梯度也大，小幅度的也小。SGD 一更新，大维度被改得猛、小维度几乎没动 → 训练抖动、难收敛
- **特征被"大嗓门"主导**：一个 1000 的特征和一个 1 的特征做加权平均时，1000 压倒一切，别的特征等于白算

LayerNorm 在每次子层运算前把特征"拉回"统一量纲。

### 具体算什么

对**每一帧的 512 维特征向量**独立做（不跨帧、不跨 batch）：

```
x ∈ R^512    （一帧的特征向量）

μ = mean(x)              ← 这 512 个数的均值
σ = std(x)               ← 这 512 个数的标准差
x_norm = (x − μ) / σ     ← 减均值、除标准差 → 均值0、方差1
output = γ · x_norm + β  ← 用学出来的 γ(缩放)、β(平移) 还原
```

`γ`、`β` 各是 512 维的**可学习参数**（[[Backpropagation|反向传播]]时和别的 W 一起调）。

### 3 维例子

`x = [1000, 1, 2]`（一个维度严重爆炸）：

```
μ ≈ 334.3,  σ ≈ 470.7
x_norm = [(1000−334.3)/470.7, (1−334.3)/470.7, (2−334.3)/470.7]
       = [ 1.414, -0.708, -0.706 ]
```

**1000 被压到 1.414，1 变成 -0.708，2 变成 -0.706**——原本差一千倍的三个数现在都在 ±1.5 范围里。"大嗓门"不再凭音量压人。

然后 `γ·x_norm+β`：网络自己学 `γ`、`β`，决定归一化后每维该恢复成多大幅度。即：**先标准化到好处理的范围，再把"最终该是什么分布"的决策权交回给网络**。

### 为什么叫"层"归一化（vs Batch Norm）

| | 求均值的方向 | 依赖 batch？ | 训练/推理行为 |
|---|---|---|---|
| **BatchNorm** | 沿 **batch 维**（同一特征跨不同样本） | 依赖（batch 太小就不稳） | 训练推理不一样（推理用滑动平均统计量） |
| **LayerNorm** | 沿 **特征维**（同一样本的 512 个特征） | **不依赖** | 训练推理**完全一样** |

```
batch 张量形状 (batch, seq, d_model=512)：

BatchNorm：沿 ↑(batch) 方向，每个 (seq, 特征) 位置跨样本归一
LayerNorm：沿 →(特征) 方向，每个 (batch, seq) 位置在自己 512 维内归一
```

**Transformer 用 LayerNorm 不用 BatchNorm**：序列任务 batch 小、长度可变，BatchNorm 不稳；LayerNorm 对单样本就能算，训练推理一致。

### pre-norm vs post-norm（论文选 pre-norm）

```
post-norm（原版 Transformer）： output = LayerNorm( x + sublayer(x) )
                                ← 归一化在残差相加"之后"，深网训练不稳

pre-norm（论文用）：            output = x + sublayer( LayerNorm(x) )
                                ← 归一化在子层"之前"
                                ← 残差流 x 干净直通，梯度沿残差一路畅通
```

**pre-norm 的好处**：残差那条路（`x + ...`）是**干净直通**的——`x` 没被归一化动过，所以从最深层到最浅层有一条"高速公路"，梯度畅通，深网训练稳得多。论文代码 `pre_lnorm: true` 就是这个选择。

### 为什么 pre-norm 还要一个"最终 LayerNorm"

pre-norm 的副作用：只对**子层输入**归一化，残差流 `x` 本身从头到尾**没被归一化**过。6 层过完，残差流是 6 次"原始 x + 各种子层输出"的累加，幅度又可能失控。所以进 decoder 前补一个 `LayerNorm(H_6)` 清理一下。post-norm 不需要（每层都归一残流），pre-norm 必须补这个收尾。

### 在本项目中的体现

论文 [[ContextTransformer]] / [[DetailTransformer]] 每层都用 pre-norm：`PositionwiseFeedForward` 和 `RelMultiHeadedAttention` 各自带一个 `LayerNorm(512)`，外加 ContextTransformer 在 decoder 前的最终 `LayerNorm`。

> 一句话：**LayerNorm = 在每个子层运算前把这一帧的 512 维特征"减均值除标准差"拉回统一量纲，再用学出来的 γ、β 决定最终分布。它压住深网数值幅度失控，让 SGD 训练能稳定收敛。**

## Adam vs SGD

### SGD：最朴素

```
W ← W − lr · g
```

直接朝负梯度方向走一步。问题：

1. **所有参数用同一个 `lr`**：但有些 `W` 的梯度常年很大、有些常年很小，同一个 `lr` 对前者太大、对后者太小
2. **mini-batch 噪声大**：每步梯度只是数据子集估的，抖动剧烈，在 loss 表面"沟壑"里来回震荡
3. **深网/Transformer 尤其敏感**：各层、各 `W` 量级差异大，naive SGD 很难调

### Adam = SGD + 两味"补丁"

**补丁一：动量（一阶矩 m）—— 平滑方向、给惯性**

不只看当前梯度，看梯度的**滑动平均**：

```
m_t = β₁·m_{t-1} + (1−β₁)·g_t      ← 梯度的指数加权平均
```

效果：方向一致的梯度累加成"惯性"（重球滚下坡，冲过小坑），方向来回乱跳的梯度相互抵消（不抖了）。

**补丁二：自适应每参数步长（二阶矩 v）—— 各维各走各的步幅**

```
v_t = β₂·v_{t-1} + (1−β₂)·g_t²     ← 每个参数各自的梯度平方滑动平均
W ← W − lr · m_t / (√v_t + ε)
```

关键在 `1/√v_t` 这个**逐参数缩放**：

- 某参数梯度常年 ~100 → `√v ≈ 100` → 步长 `≈ lr·m/100 ≈ lr`（自动缩小）
- 某参数梯度常年 ~0.001 → `√v ≈ 0.001` → 步长 `≈ lr·m/0.001 ≈ lr`（自动放大）

**不管原始梯度量级差多少倍，都被归一化到差不多的有效步长**。这就是"adaptive"——每个参数按自己的脾气调步幅。

### 完整公式 + 默认值

```
m_t = 0.9·m_{t-1} + 0.1·g_t                      （动量）
v_t = 0.999·v_{t-1} + 0.001·g_t²                 （方差）
m̂_t = m_t / (1 − 0.9^t)                          （偏差修正，初期很重要）
v̂_t = v_t / (1 − 0.999^t)
W ← W − lr · m̂_t / (√v̂_t + 1e-8)
```

> **偏差修正**：`m`、`v` 初始是 0，开头几步被严重低估；除以 `(1−β^t)` 补回真实量级。这是 Adam 训练初期不崩的关键，也是 Transformer 要配 **warmup**（前几千步 `lr` 从 0 慢慢升）的原因——给 `v_t` 估稳的时间。

### 对比表

| | SGD | Adam |
|---|---|---|
| 更新 | `W − lr·g` | `W − lr·m̂/(√v̂+ε)` |
| 用历史梯度？ | 只看当前 | 一阶矩 m（动量，平滑方向） |
| 每参数自适应步长？ | 否，全用同一 `lr` | 是，按各自梯度方差缩放 |
| 噪声/抖动 | 大 | 小（动量平滑） |
| 调参难度 | `lr` 难调 | 较鲁棒，默认值常直接可用 |
| Transformer | 易震荡/卡 | **业界标配** |

### 直觉

- **SGD**：徒步者下坡，每步按当前脚下坡度走，遇到坑洼来回弹
- **SGD+动量**：重球滚下坡，有惯性，冲过小坑
- **Adam**：重球 + **每个方向各自带独立悬挂**——颠簸的方向自动减震、平顺的方向放心加速

### Noam 学习率调度

论文用 Adam 配 Noam 调度（`train/utils.get_noam_lr_scheduler`）：

```
if iteration < warm_iters(8000):
    lr ∝ iteration · warm_iters^(-1.5)     ← warmup：从 0 线性升到峰值
else:
    lr ∝ 1/√iteration                       ← 衰减
```

warmup 让初期 `lr` 小（等 Adam 的 `v_t` 估稳），避免前几步把参数带偏；之后慢慢衰减精修。这是 Transformer 训练稳定的标准配方。

### 在本项目中的体现

论文 [[MotionInbetweeningTwoStage]] 用 Adam（`β₁=0.9, β₂=0.999, ε=1e-8`）+ Noam（warmup 8000）。Context 的 `lr=0.0625`、Detail 的 `lr=0.025`。两阶段顺序训练：先训 Context 冻结，再训 Detail。

> 一句话：**SGD 是"朝当前梯度走一步"；Adam 是"朝平滑后的梯度方向走，且每个参数按自己历史梯度的剧烈程度自动调步长"。** 动量给方向以惯性、自适应给步幅以个性，两者让深网训练稳得多。
