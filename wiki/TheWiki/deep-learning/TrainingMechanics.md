# 训练机制（LayerNorm / Adam / SGD）

本页收集让深网（尤其是 [[Transformer]]）能稳定训练的两个机制：**LayerNorm**（压住数值幅度）与 **Adam**（稳健的优化器）。

---

## LayerNorm：压住深网里数值"失控"

### 解决什么问题

一个 6 层 Transformer，数据要连过 12 个子层（每层 attention + FFN）。每过一次特征值就被矩阵乘、非线性变换。问题：**各维度的数值幅度会越走越分叉**——有的维度爆炸到几千，有的缩到零点零零几。

幅度失衡带来两个灾难：

- **梯度失衡**：大幅度的维度梯度也大，小幅度的也小。SGD 一更新，大维度被改得猛、小维度几乎没动 → 训练抖动、难收敛
- **特征被"大嗓门"主导**：一个 1000 的特征和一个 1 的特征做加权平均时，1000 压倒一切，别的特征等于白算

LayerNorm 在每次子层运算前把特征"拉回"统一量纲。

### 具体算什么

对**每一帧的 512 维特征向量**独立做（不跨帧、不跨 batch）：

```
x ∈ R^512    （一帧的特征向量）

μ = mean(x)              ← 这 512 个数的均值
σ = std(x)               ← 这 512 个数的标准差
x_norm = (x − μ) / σ     ← 减均值、除标准差 → 均值0、方差1
output = γ · x_norm + β  ← 用学出来的 γ(缩放)、β(平移) 还原
```

`γ`、`β` 各是 512 维的**可学习参数**（[[Backpropagation|反向传播]]时和别的 W 一起调）。

### 3 维例子

`x = [1000, 1, 2]`（一个维度严重爆炸）：

```
μ ≈ 334.3,  σ ≈ 470.7
x_norm = [(1000−334.3)/470.7, (1−334.3)/470.7, (2−334.3)/470.7]
       = [ 1.414, -0.708, -0.706 ]
```

**1000 被压到 1.414，1 变成 -0.708，2 变成 -0.706**——原本差一千倍的三个数现在都在 ±1.5 范围里。"大嗓门"不再凭音量压人。

然后 `γ·x_norm+β`：网络自己学 `γ`、`β`，决定归一化后每维该恢复成多大幅度。即：**先标准化到好处理的范围，再把"最终该是什么分布"的决策权交回给网络**。

### 为什么叫"层"归一化（vs Batch Norm）

| | 求均值的方向 | 依赖 batch？ | 训练/推理行为 |
|---|---|---|---|
| **BatchNorm** | 沿 **batch 维**（同一特征跨不同样本） | 依赖（batch 太小就不稳） | 训练推理不一样（推理用滑动平均统计量） |
| **LayerNorm** | 沿 **特征维**（同一样本的 512 个特征） | **不依赖** | 训练推理**完全一样** |

```
batch 张量形状 (batch, seq, d_model=512)：

BatchNorm：沿 ↑(batch) 方向，每个 (seq, 特征) 位置跨样本归一
LayerNorm：沿 →(特征) 方向，每个 (batch, seq) 位置在自己 512 维内归一
```

**Transformer 用 LayerNorm 不用 BatchNorm**：序列任务 batch 小、长度可变，BatchNorm 不稳；LayerNorm 对单样本就能算，训练推理一致。

### pre-norm vs post-norm（论文选 pre-norm）

```
post-norm（原版 Transformer）： output = LayerNorm( x + sublayer(x) )
                                ← 归一化在残差相加"之后"，深网训练不稳

pre-norm（论文用）：            output = x + sublayer( LayerNorm(x) )
                                ← 归一化在子层"之前"
                                ← 残差流 x 干净直通，梯度沿残差一路畅通
```

**pre-norm 的好处**：残差那条路（`x + ...`）是**干净直通**的——`x` 没被归一化动过，所以从最深层到最浅层有一条"高速公路"，梯度畅通，深网训练稳得多。论文代码 `pre_lnorm: true` 就是这个选择。

### 为什么 pre-norm 还要一个"最终 LayerNorm"

pre-norm 的副作用：只对**子层输入**归一化，残差流 `x` 本身从头到尾**没被归一化**过。6 层过完，残差流是 6 次"原始 x + 各种子层输出"的累加，幅度又可能失控。所以进 decoder 前补一个 `LayerNorm(H_6)` 清理一下。post-norm 不需要（每层都归一残流），pre-norm 必须补这个收尾。

### 在本项目中的体现

论文 [[ContextTransformer]] / [[DetailTransformer]] 每层都用 pre-norm：`PositionwiseFeedForward` 和 `RelMultiHeadedAttention` 各自带一个 `LayerNorm(512)`，外加 ContextTransformer 在 decoder 前的最终 `LayerNorm`。

> 一句话：**LayerNorm = 在每个子层运算前把这一帧的 512 维特征"减均值除标准差"拉回统一量纲，再用学出来的 γ、β 决定最终分布。它压住深网数值幅度失控，让 SGD 训练能稳定收敛。**

## Adam vs SGD

### SGD：最朴素

```
W ← W − lr · g
```

直接朝负梯度方向走一步。问题：

1. **所有参数用同一个 `lr`**：但有些 `W` 的梯度常年很大、有些常年很小，同一个 `lr` 对前者太大、对后者太小
2. **mini-batch 噪声大**：每步梯度只是数据子集估的，抖动剧烈，在 loss 表面"沟壑"里来回震荡
3. **深网/Transformer 尤其敏感**：各层、各 `W` 量级差异大，naive SGD 很难调

### Adam = SGD + 两味"补丁"

**补丁一：动量（一阶矩 m）—— 平滑方向、给惯性**

不只看当前梯度，看梯度的**滑动平均**：

```
m_t = β₁·m_{t-1} + (1−β₁)·g_t      ← 梯度的指数加权平均
```

效果：方向一致的梯度累加成"惯性"（重球滚下坡，冲过小坑），方向来回乱跳的梯度相互抵消（不抖了）。

**补丁二：自适应每参数步长（二阶矩 v）—— 各维各走各的步幅**

```
v_t = β₂·v_{t-1} + (1−β₂)·g_t²     ← 每个参数各自的梯度平方滑动平均
W ← W − lr · m_t / (√v_t + ε)
```

关键在 `1/√v_t` 这个**逐参数缩放**：

- 某参数梯度常年 ~100 → `√v ≈ 100` → 步长 `≈ lr·m/100 ≈ lr`（自动缩小）
- 某参数梯度常年 ~0.001 → `√v ≈ 0.001` → 步长 `≈ lr·m/0.001 ≈ lr`（自动放大）

**不管原始梯度量级差多少倍，都被归一化到差不多的有效步长**。这就是"adaptive"——每个参数按自己的脾气调步幅。

### 完整公式 + 默认值

```
m_t = 0.9·m_{t-1} + 0.1·g_t                      （动量）
v_t = 0.999·v_{t-1} + 0.001·g_t²                 （方差）
m̂_t = m_t / (1 − 0.9^t)                          （偏差修正，初期很重要）
v̂_t = v_t / (1 − 0.999^t)
W ← W − lr · m̂_t / (√v̂_t + 1e-8)
```

> **偏差修正**：`m`、`v` 初始是 0，开头几步被严重低估；除以 `(1−β^t)` 补回真实量级。这是 Adam 训练初期不崩的关键，也是 Transformer 要配 **warmup**（前几千步 `lr` 从 0 慢慢升）的原因——给 `v_t` 估稳的时间。

### 对比表

| | SGD | Adam |
|---|---|---|
| 更新 | `W − lr·g` | `W − lr·m̂/(√v̂+ε)` |
| 用历史梯度？ | 只看当前 | 一阶矩 m（动量，平滑方向） |
| 每参数自适应步长？ | 否，全用同一 `lr` | 是，按各自梯度方差缩放 |
| 噪声/抖动 | 大 | 小（动量平滑） |
| 调参难度 | `lr` 难调 | 较鲁棒，默认值常直接可用 |
| Transformer | 易震荡/卡 | **业界标配** |

### 直觉

- **SGD**：徒步者下坡，每步按当前脚下坡度走，遇到坑洼来回弹
- **SGD+动量**：重球滚下坡，有惯性，冲过小坑
- **Adam**：重球 + **每个方向各自带独立悬挂**——颠簸的方向自动减震、平顺的方向放心加速

### Noam 学习率调度

论文用 Adam 配 Noam 调度（`train/utils.get_noam_lr_scheduler`）：

```
if iteration < warm_iters(8000):
    lr ∝ iteration · warm_iters^(-1.5)     ← warmup：从 0 线性升到峰值
else:
    lr ∝ 1/√iteration                       ← 衰减
```

warmup 让初期 `lr` 小（等 Adam 的 `v_t` 估稳），避免前几步把参数带偏；之后慢慢衰减精修。这是 Transformer 训练稳定的标准配方。

### 在本项目中的体现

论文 [[MotionInbetweeningTwoStage]] 用 Adam（`β₁=0.9, β₂=0.999, ε=1e-8`）+ Noam（warmup 8000）。Context 的 `lr=0.0625`、Detail 的 `lr=0.025`。两阶段顺序训练：先训 Context 冻结，再训 Detail。

> 一句话：**SGD 是"朝当前梯度走一步"；Adam 是"朝平滑后的梯度方向走，且每个参数按自己历史梯度的剧烈程度自动调步长"。** 动量给方向以惯性、自适应给步幅以个性，两者让深网训练稳得多。
