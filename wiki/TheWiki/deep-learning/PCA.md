# 主成分分析（PCA）与 SVD

> 线性代数地基页。为什么 [[QNN]] 只输出 ~100 个 PCA 系数就能重建 18546 顶点的裙子？答案在这一页。
> 先读 [[NeuralNetworkBasics]]（网络怎么学），再读本页（数据怎么降维）。

## 1. 这一页回答的问题

一段布料动画 = 5000 帧，每帧 18546 顶点 × 3 坐标 = **55638 个数**。直接处理 55638 维不现实。

但布料形变高度有规律，问一句：

> 这 5000 帧，真的需要 55638 个数才能描述吗？

PCA 的答案是**不需要**。它能从数据里找出 ~100 个"标准形变模式"，使得任何一帧都近似等于：

$$
\text{帧} \approx \underbrace{\text{基线}}_{\text{平均形}} + \underbrace{w_1 B_1 + w_2 B_2 + \cdots + w_k B_k}_{\text{100 张"形变图"按系数加权}}
$$

- $B_i$：第 $i$ 个模式，本身也是 55638 维的一张"形变图"（告诉每个顶点往哪动）；
- $w_i$：这一帧在模式 $i$ 上开的分量（一个标量，可正可负）；
- $k \approx 100$：远小于 55638。

**网络的任务从"写 55638 个顶点坐标"降级成"报 100 个旋钮 $w_i$ 的位置"。** 剩下的交给写死的线性公式还原。

## 2. 数据摆放：一张大表

把 5000 帧排成矩阵，每行一帧：

$$
X = \begin{bmatrix} \text{帧1的 } d \text{ 个数} \\ \text{帧2的 } d \text{ 个数} \\ \vdots \\ \text{帧5000的 } d \text{ 个数} \end{bmatrix} \in \mathbb{R}^{m \times d}, \qquad m = 5000,\; d = 55638
$$

**先减平均帧**（逐坐标平均得到 $\mu$，每行减去）。我们要找的是"变化的方向"，数据整体往某方向偏不算形变。减完平均后的矩阵仍记作 $X$。论文里 rest 网格（静止垂坠形）就充当这条基线。

## 3. 方差：先复习定义

给一组数 $z_1,\dots,z_m$，均值 $\bar z$，**方差 = 离均值距离平方的平均**：

$$
\operatorname{Var}(z) = \frac{1}{m-1}\sum_{t=1}^{m}\bigl(z_t - \bar z\bigr)^2
$$

读法："这些数平均偏离均值多远，平方后是这么大"。开根号 = 标准差，更直观。除以 $m$ 还是 $m-1$ 只是约定，不影响任何方向性结论。

**"某个方向上的方差"**：设 $u$ 是一个单位方向向量（$\lVert u \rVert = 1$）。把每一帧往 $u$ 上投影，得到 $m$ 个标量 $p_t = u^\top v_t$（$v_t$ = 第 $t$ 帧，已居中）。因为数据居中，$p_t$ 的均值是 0，所以它们的方差 = 平方的平均：

$$
\text{沿 } u \text{ 的方差} = \frac{1}{m-1}\sum_{t=1}^{m} p_t^2
= \frac{1}{m-1}\sum_{t=1}^{m} u^\top v_t v_t^\top u
= u^\top \Bigl[\frac{1}{m-1}\sum_{t=1}^{m} v_t v_t^\top\Bigr] u
$$

## 4. 协方差矩阵：谁跟谁一起动

上面中括号里的东西就是**协方差矩阵**：

$$
C = \frac{1}{m-1} X^\top X \in \mathbb{R}^{d \times d}
$$

$C$ 第 $j$ 行第 $k$ 列 = 第 $j$ 个坐标和第 $k$ 个坐标在 5000 帧里的协方差：

- $> 0$：习惯一起往同方向动（如裙摆同一片的两块顶点）；
- $< 0$：习惯反着动（一处鼓起另一处凹下）；
- $\approx 0$：各动各的，没关系。

**C 就是这 5000 帧关于"共同运动"的全部统计信息。** 之后所有运算都发生在这张表上。

## 5. 关键推导：特征值 = 方向方差

代上面两步，任意单位方向 $u$ 的方向方差是：

$$
\text{沿 } u \text{ 的方差} = u^\top C u
$$

若 $u$ 恰好是 $C$ 的特征向量（$C u = \lambda u$，且 $\lVert u \rVert = 1$）：

$$
u^\top C u = u^\top (\lambda u) = \lambda\,(u^\top u) = \lambda
$$

**结论：特征值 $\lambda$ 不是被"规定"出来的，是被算出来的——它就是数据沿该特征向量方向散开的方差。** 特征向量 = 方向，特征值 = 该方向上的方差量。

## 6. PCA = 协方差矩阵的特征分解

想要"散得最开的方向"，即最大化 $u^\top C u$ 且 $\lVert u \rVert=1$（带约束最优化，拉格朗日乘子法），解恰是：

$$
C u = \lambda u
$$

所以按特征值从大到小取前 $k$ 个特征向量，就是依次"方差最大的方向"：

| 量 | 身份 |
|---|---|
| 特征向量 $u_i$ | 第 $i$ 个模式方向 = **PCA 基底 $B_i$** |
| 特征值 $\lambda_i$ | 该方向解释的方差（越大越重要，决定排序）|
| 总方差 | $\sum_i \lambda_i = \operatorname{tr}(C)$ |
| 前 $k$ 解释比例 | $\dfrac{\lambda_1+\cdots+\lambda_k}{\lambda_1+\cdots+\lambda_d}$，裙子场景 ≥ 99% |

## 7. 特征值"够不够 100 个"？

**对称矩阵永远有 $d$ 个实特征值（且 $C$ 半正定，全部 ≥ 0），不存在个数不够。**

但**正特征值个数有上限**：居中后数据秩 ≤ $\min(d,\;m-1)$，所以

$$
\lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_{4999} > 0,\qquad \lambda_{5000} = \cdots = \lambda_{55638} = 0
$$

**特征值 = 0 的方向** = 数据在那些方向从不变化（投影恒为 0），对重建无贡献。

若数据真实自由度极少（比如只有 3 个正特征值），那不是问题而是好消息：**保留 3 个模式重建就已完美**。模式是从数据里长出来的，数据里没有的形变，任何模式也表达不出来。

## 8. SVD：任何矩阵 = 旋转 × 缩放 × 旋转

协方差矩阵 $C$ 有 $d^2 \approx 31$ 亿个元素，直接构造再特征分解不可行。**SVD 是绕开它算 PCA 的标准做法。**

任意矩阵 $X \in \mathbb{R}^{m \times d}$ 都能写成三块相乘：

$$
X = U\,\Sigma\,V^\top
$$

| 块 | 形状 | 含义 |
|---|---|---|
| $U$ | $m \times m$ | 帧空间的正交基（列 $u_i$ 彼此垂直、长度 1）|
| $\Sigma$ | $m \times d$ | 对角阵，对角值 $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$，其余 0 |
| $V$ | $d \times d$ | 坐标空间的正交基（列 $v_i$）|

几何含义：**先转（$V^\top$）、再沿轴拉伸（$\Sigma$）、再转（$U$）**。线性代数定理：任何线性变换都能写成"旋转 + 缩放 + 旋转"，无剪切。

### 展开成"模式的加权和"

$$
X = \sigma_1\, u_1 v_1^\top \;+\; \sigma_2\, u_2 v_2^\top \;+\; \cdots
$$

每项 $u_i v_i^\top$ 是"秩 1 模板"，用裙子语言翻译：

- $v_i$（$d$ 维）：第 $i$ 个**形变方向** = PCA 模式 $B_i$；
- $u_i$（$m$ 维）：5000 帧各自在该方向上的**参与强度**；
- $\sigma_i$：该模式在整个数据集里的**总大小**。

因为 $\sigma_1 \ge \sigma_2 \ge \cdots$，这个和式天然"重要模式在前"。截断到前 $k$ 项是**所有"用 $k$ 个模式近似 $X$"里误差最小的**（Eckart–Young 定理）——这就是"取前 100"的数学依据。

### 手算例子（3 帧 × 2 坐标，数据完全共线）

$$
X = \begin{bmatrix} 1 & 1 \\ 2 & 2 \\ 3 & 3 \end{bmatrix}
$$

- $v_1 = (1,1)/\sqrt{2}$（数据散开的方向）；
- $X v_1 = (\sqrt2,\ 2\sqrt2,\ 3\sqrt2)$，长度 $= \sqrt{28} = \sigma_1$；
- $u_1 = X v_1 / \sigma_1 = (1,2,3)/\sqrt{14}$（每帧参与强度）；
- 验证 $X = \sigma_1\, u_1 v_1^\top$ ✓。

注意 $u_1$、$v_1$ **都不是某一行/某一列**，而是把整个 $X$ 当整体算出的公共方向——裙子的 $B_1$ 同理。

## 9. SVD 和 PCA 是同一件事

把 $X = U\Sigma V^\top$ 代进协方差：

$$
C = \frac{1}{m-1} X^\top X = V\Bigl(\frac{\Sigma^\top\Sigma}{m-1}\Bigr)V^\top
$$

这正是 $C$ 的特征分解，于是 SVD **一石三鸟**：

| 想要的量 | 从 SVD 读 |
|---|---|
| PCA 模式方向 | $V$ 的列（$B = V_{:,1:k}$）|
| 特征值 = 方差 | $\lambda_i = \sigma_i^2 / (m-1)$ |
| 每帧系数 | $X v_i = \sigma_i u_i$（一次分解白送）|

**为什么用 SVD 而不是 `eig(C)`**：不用构造 31 亿元素的大矩阵、数值更稳、`np.linalg.svd` 一行完成。

## 10. 系数与重建

设 $B = [B_1, \dots, B_k] \in \mathbb{R}^{d \times k}$（前 $k$ 个特征向量作列）。每帧系数：

$$
W = X B \in \mathbb{R}^{m \times k}, \qquad W_{t,i} = \text{第 } t \text{ 帧在模式 } i \text{ 上的分量}
$$

还原（对居中数据）：

$$
\hat X = W B^\top = U_k \Sigma_k V_k^\top \approx X
$$

还原成布料网格（加上基线）：

$$
M_t = \underbrace{rest + \mu}_{\text{基线}} + \sum_{i=1}^{k} W_{t,i}\, B_i
$$

## 11. 落地：裙子的完整流程（5000 帧 → B/w/λ）

```python
import numpy as np
m, d = 5000, 55638          # 帧数 × (18546 顶点 × 3)

# (a) D0: 5000 帧网格；先减骨盆刚体位移（局部系），再减 rest → 非刚体位移
rest        # (55638,)  基线：rest pose 下稳态垂坠形
D  = D0 - rest             # (5000, 55638)
mu = D.mean(0)             # (55638,)  平均形变（运动对称时≈0）
X  = D - mu                # (5000, 55638)  居中

# (b) 一步 SVD，全部分量齐活
U, s, Vt = np.linalg.svd(X, full_matrices=False)
#  U (5000,5000)   s (5000,)   Vt (5000,55638)

k        = 100
B        = Vt[:k].T        # (55638, 100)  模式方向，列两两垂直、单位长 = PCA 基底
lam      = s[:k]**2 / (m-1)   # (100,)      特征值 = 各模式方差
W        = X @ B           # (5000, 100)   每帧系数（网络预测的就是每帧这一行）

# (c) 还原与误差
recon    = W @ B.T         # (5000, 55638)
err      = np.linalg.norm(X - recon)/np.linalg.norm(X)   # ≈0.00x
```

### 接到两个网络

```python
# 训练：造监督信号
w_GT = X @ B                            # 每帧的"正确答案"
# 配对 → 训练集 {(x_1, w_GT_1), …, (x_5000, w_GT_5000)}
# x_t = 第 t 帧骨骼非刚体位移 (234×3 ≈ 702 维)

# 推理：每帧
x_t    = 本帧骨骼非刚体位移              # (702,)
ŵ      = MLP_Skinning(x_t)             # (100,)  网络唯一输出
mesh_t = base_skin + ŵ @ B_skin.T      # (55638,) 写死公式线性还原
```

> 网络只输出 100 个数；**PCA 把"输出顶点"这件不可能的事，降级成了"输出旋钮位置"。**

## 12. 两级 PCA：为什么 skinning 管低频、QNN 管高频

裙子用了**两套不同的 PCA**（见 Fig 8 说明），对应两个网络：

| | skinning 的 PCA | QNN（neural shape）的 PCA |
|---|---|---|
| 数据（$D$）| rest ↔ GT 的非刚体位移 | skinning 输出 ↔ GT 的**残差** |
| 基底频段 | 低频（整体摆、粗形状）| 高频（局部褶皱）|
| 重建 | 粗网格 $= base + \sum w^s_i B^s_i$ | 最终网格 $=$ 粗网格 $+ \sum w^q_j B^q_j$ |

**为什么拆两级**：

1. **残差学习**：QNN 目标只是"粗网格没拟合掉的部分"，幅值小、方差集中，好训。
2. **容量分配**：若只有一套 PCA（建在总位移上），前 100 个主成分被低频方差挤满，褶皱排到第几百位、被截断扔掉。残差 PCA 构造时低频已被减掉，**其前 100 个主成分天然全是褶皱方向**——100 个系数才够表达褶皱而不欠拟合。
3. **L2 梯度不被淹没**：L2 按幅值平方计权，粗误差会淹没小振幅褶皱；分两步后 QNN 的 loss 只算残差，褶皱在它自己的 loss 里是主角。

## 13. 一句话收束

> PCA = 在数据里找"散得最开的方向"，按方差排序取前 $k$ 个；模式 $B_i$ = 特征向量，方差 $\lambda_i$ = 特征值，系数 $w$ = 投影。**PCA 不"理解"布料，只是统计学家；它把 55638 维的活变简单，让 [[QNN]] 只用 100 个旋钮就能拧出整片裙子。**
