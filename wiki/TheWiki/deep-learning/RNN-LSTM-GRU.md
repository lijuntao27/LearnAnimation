# RNN / LSTM / GRU 单元原理

> 承接 [[RecurrentNetworks]]（RNN 与 Encoder-Decoder 范式）。那篇讲 RNN 在**网络级**怎么处理序列；这篇下沉到**单元级**，用机器翻译做贯穿例子，拆解裸 RNN、LSTM、GRU 各自的记忆机制与递推公式。原始资料的完整中文译本见 [[Recurrent_neural_network-中文翻译]]。

## 0. 问题舞台：机器翻译为何需要"记忆"

机器翻译的本质：把一句话从语言 A 变成语言 B。

- 输入、输出都是**变长序列**（句子长短不一）；
- **顺序极重要**（"猫咬狗" ≠ "狗咬猫"）；
- 两种语言**词序往往不同**（"the man who is standing there" 译成中文定语整体前移：站在那里的那个男人）；
- 一个词译得对不对，常依赖**离它很远的词**（英语主谓一致：句首 The **cats** 决定句尾 **are**）。

所以模型须同时具备两种能力：① 把整句"读进去"并记住（哪怕信息隔很远）；② 逐词生成目标句，且每步用词取决于"源句记住了什么 + 已译出什么"。这正是 RNN 家族当年在机器翻译里的分工舞台。

## 1. 骨架：Encoder-Decoder（seq2seq）

把翻译拆成两个 RNN 前后接力：

```
源句:  I  have  lived  in  Beijing  for  three  years
       │   │     │     │     │      │    │      │
       ▼   ▼     ▼     ▼     ▼      ▼    ▼      ▼
   ┌──────────────── Encoder RNN ────────────────┐
   │  每读一个词，更新一次记忆向量 h             │
   └──────────────────────────────────────────────┘
                         │
                    最后的 h（= context 向量 c，整句浓缩）
                         │
                         ▼
   ┌──────────────── Decoder RNN ────────────────┐
   │  从 c 出发，逐词吐出: 我 → 在 → 北京 → 住了 → 三年 │
   └──────────────────────────────────────────────┘
```

- **Encoder**：把源语言单词逐个喂入，每步更新隐藏状态 $h_t$；读完末词后把 $h_T$ 当作整句压缩表示，记为 context 向量 $c$。
- **Decoder**：以 $c$ 为初始状态逐步生成目标语言，每一步都以"上一步译出的词"为输入、用 softmax 在目标词表上选词：

$$p(y_1,\dots,y_m) = \prod_{k=1}^{m} p(y_k \mid y_{<k},\ c)$$

骨架解决"输入输出长度不同"；而**每个单元内部怎么记忆**，是 RNN / LSTM / GRU 的差别所在。

## 2. 裸 RNN：最简单的记忆单元

### 递推式

$$h_t = \tanh\big(W_{hh}\, h_{t-1} + W_{xh}\, x_t + b\big)$$

逐项读：

| 项                         | 含义                      |
| ------------------------- | ----------------------- |
| $x_t$                     | 当前读到的词（的词向量）            |
| $h_{t-1}$                 | 此前所有词的记忆浓缩              |
| $W_{hh}h_{t-1}+W_{xh}x_t$ | "旧记忆"与"新词"的线性混合         |
| $\tanh$                   | 压到 $(-1,1)$，引入非线性、防幅度爆炸 |

沿时间展开就是反复套同一单元（三个 $W$ 所有时间步**共享**）：

```
x₁ →[RNN]→ h₁ →[RNN]→ h₂ →[RNN]→ h₃ → ... → h_T = c
       ↑         ↑         ↑
      h₀(零向量)
```

### 问题①：每次都是"全盘改写"

直觉：旧记忆 $h_{t-1}$ 与新词先混成一个向量再过 $\tanh$——新 $h_t$ 里没有"被保护的位置"，旧记忆被**整体改写成新东西**。好比听新词就把整本笔记重誊一遍：听 3 个词尚可，听 30 个词时开头早被冲没。对应到翻译：**源句一长，句首信息（主语、时态）在 encoder 记忆中被冲淡**，decoder 译后半句自然出错。

### 问题②：训练也学不动（梯度消失）

BPTT 回传误差每跨一个时间步乘一次 $W_{hh}$（及 $\tanh'$）：

$$\frac{\partial C}{\partial h_1} \approx \frac{\partial C}{\partial h_T}\, W_{hh}^{\,T-1}$$

- $W_{hh}$ 特征值 $<1$：连乘 → 梯度 $\to0$ → 句首词学不动（**梯度消失**）；
- $>1$：连乘 → 梯度爆炸。

结果：裸 RNN 理论可记、实际"记不住远词"，训练还不稳定。

## 3. LSTM：档案室 + 三道门

> 1997 Hochreiter & Schmidhuber，为解决"梯度消失导致长程遗忘"而设计（详见 [[RecurrentNetworks|LSTM：给 RNN 打补丁]]）。

### 结构直觉

在 $h_t$ 之外加一条贯穿时间步的**细胞状态 $C_t$**（传送带/档案室），信息可近乎不衰减地直线流动；三个**门**（sigmoid 输出 $0\sim1$ 的可学习阀门）控制读写：

```
                ┌──────────────────────────────────────┐
   C_{t-1} ─────┤── 遗忘门 f_t 决定丢多少 ──⊕──→ C_t   │  传送带，直线贯穿
                │                              ▲       │
   x_t, h_{t-1} ─┤→ 输入门 i_t + 候选 C̃_t      │       │  写入新内容
                │                              │       │
                └── 输出门 o_t ──→ 从 C_t 读出 → h_t    │
                └──────────────────────────────────────┘
```

### 五组公式

记 $[h_{t-1}, x_t]$ 为旧隐藏与当前词的拼接；$\sigma$ 为 sigmoid，$\odot$ 为逐元素乘。

**① 遗忘门——旧档案丢多少：**

$$f_t = \sigma\big(W_f\,[h_{t-1}, x_t] + b_f\big)$$

分量 $\to0$ → 对应位置清零（忘掉）；$\to1$ → 原样保留。

**② 输入门——新信息写多少：**

$$i_t = \sigma\big(W_i\,[h_{t-1}, x_t] + b_i\big)$$

**③ 候选内容——此刻值得记的新信息：**

$$\tilde C_t = \tanh\big(W_C\,[h_{t-1}, x_t] + b_C\big)$$

（用 $\tanh$ 因为写入量可正可负、范围 $(-1,1)$——tanh 见 [[NeuralNetworkBasics|激活函数]] 讨论。）

**④ 更新细胞状态——保留旧 + 写入新：**

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde C_t$$

**⑤ 输出门 + 隐藏状态——档案暴露多少：**

$$o_t = \sigma\big(W_o\,[h_{t-1}, x_t] + b_o\big),\qquad h_t = o_t \odot \tanh(C_t)$$

### 标量玩具演算（维度压成 1 示意）

设上一步细胞记忆 $C_{t-1}=5$（存着"主语复数、谓语要用 are"这类跨距离信息），读到新词 $x_t$：

| 量 | 取值 | 含义 |
|---|---|---|
| 遗忘门 $f_t$ | 0.98 | 旧档案几乎全留 |
| 输入门 $i_t$ | 0.1 | 新词只写一点 |
| 候选 $\tilde C_t$ | 3 | 候选内容 |
| 更新 | $0.98\times5 + 0.1\times3 = 5.2$ | 记忆几乎未被动摇 |

对比裸 RNN 的"全盘改写"：读到无关紧要的修饰词时，$f_t\approx1,\ i_t\approx0$，$C$ 几乎原封不动穿过；等读到关键词（如句尾谓语）再开门读写。

### 为何缓解梯度消失

更新式 $C_t = f_t\odot C_{t-1} + \cdots$ 给误差反传一条**直线捷径**：从 $C_t$ 到 $C_{t-1}$ 梯度乘的是 $f_t$（学出来的、常接近 1 的数），而非反复乘 $W_{hh}$。**能记住，就能学。**

> LSTM 没有改变"逐步循环、不能并行、有损压缩"三个根本缺点——只是让"记多久"变得**可学**。

## 4. GRU：精简到两个门

> 2014 Cho 等人在 RNN encoder-decoder 机器翻译中提出（Kyunghyun Cho et al., 2014）。

LSTM 的"细胞状态 $C_t$ + 隐藏状态 $h_t$"被合并成一个 $h_t$；门从三个减到两个。

**重置门 $r_t$**——计算候选时忽略多少旧记忆：

$$r_t = \sigma\big(W_r\,[h_{t-1}, x_t] + b_r\big)$$

**更新门 $z_t$**——新旧状态各占多少：

$$z_t = \sigma\big(W_z\,[h_{t-1}, x_t] + b_z\big)$$

**候选新状态**（用 $r_t$ 门控旧记忆后再取 $\tanh$）：

$$\tilde h_t = \tanh\big(W_h\,[\,r_t \odot h_{t-1},\; x_t] + b_h\big)$$

**最终隐藏状态**（$z_t$ 做新旧插值）：

$$h_t = z_t \odot \tilde h_t + (1 - z_t) \odot h_{t-1}$$

直觉：

- $r_t\to0$ → 候选忽略旧记忆、只看当前词——适合丢弃无关旧上下文；
- $z_t\to1$ → 大幅采纳新候选；$z_t\to0$ → 几乎保留旧 $h$——起到类似 LSTM 遗忘门"长期携带信息"的作用。

GRU 无独立 $C$，参数更少（三套 $W$ vs LSTM 四套），机器翻译等任务上效果与 LSTM 大致相当。

## 5. 三方对比

| | 裸 RNN | LSTM | GRU |
|---|---|---|---|
| 记忆载体 | 仅 $h_t$（每步全量改写） | $C_t$（传送带）+ $h_t$ | 仅 $h_t$（门控改写比例） |
| 门数 | 无 | 3（遗忘/输入/输出） | 2（重置/更新） |
| 参数/单元 | 最少 | 最多 | 居中 |
| 长程记忆 | ✗ 梯度消失 | ✓ 细胞状态直线传 | ✓ $z_t\approx0$ 时保留 |
| 训练稳定性 | 差 | 好 | 好 |
| 机器翻译角色 | 几乎不用 | seq2seq 标配（2014–2016） | seq2seq 标配、更快 |
| 根本代价 | — | 串行、不能并行 | 同左 |

**一句话**：裸 RNN 是"每来一个新词就重写整本笔记"；LSTM 是"可只擦改部分页的档案 + 三道门管读写"；GRU 是"档案与笔记合并、只留两道门的轻量版"。

## 6. 后续：注意力 / Transformer 的接力

在机器翻译中，seq2seq（LSTM/GRU）把整句压进一个 context 向量 $c$，长句仍有**信息瓶颈**。注意力让 decoder 每译一词都能回头看源句每个位置；Transformer 干脆用自注意力并行地让所有词互相关联（见 [[Transformer]]、[[SelfAttention]]），MT 由此转向。LSTM/GRU 的门控思想仍是序列建模基础，且在动画领域作为 RNN 基线（如 [[RecurrentNetworks|ERD-QV 的 LSTM]]）继续以对比方法出现。
