# 卷积神经网络（CNN）

> 来源：Nielsen《Neural Networks and Deep Learning》Ch.6。解决"全连接网络分类图像为什么不对、怎么利用图像空间结构"的问题，是深度网络能落地图像识别的关键架构。

## 为什么要 CNN：全连接网络无视空间结构

[[NeuralNetworkBasics|MLP]] 的全连接层把每个像素连到每个隐藏神经元，对"相距远"与"相距近"的像素一视同仁——图像的空间结构（边缘、角、局部形状）只能靠训练数据自己推断。CNN 反过来：**把空间结构直接刻进架构**。

CNN 用三个基本思想：**局部感受野、共享权重、池化**。

## 三个基本思想

### 1. 局部感受野（local receptive fields）

不把每个输入像素连到每个隐藏神经元，只连到输入图像的小局部区域（如 $5\times5$，即 25 个像素）：

- 隐藏神经元只"看"自己的小窗口，学分析这窗口
- 窗口**滑过**整幅图：$28\times28$ 输入 + $5\times5$ 感受野 → $24\times24$ 隐藏神经元
- 窗口每次移动的像素数叫**步长（stride）**（通常 1）

### 2. 共享权重与偏置（shared weights & biases）

所有隐藏神经元用**同一套**权重与偏置。对第 $j,k$ 个隐藏神经元：

$$
\sigma\left(b+\sum_{l=0}^{4}\sum_{m=0}^{4}w_{l,m}\,a_{j+l,k+m}\right)
$$

含义：**所有神经元检测同一个特征，只是在图像不同位置。** 直觉：能在左上角检测垂直边的滤波器，在右下角也有用——**平移不变性**（把猫挪一点仍是猫）。

- 输入层 → 隐藏层的映射叫**特征映射（feature map）**；定义它的共享权重+偏置叫**核（kernel）/ 滤波器（filter）**
- 一个特征映射只能检测一种特征；完整卷积层由**多个**特征映射组成（如 20、40 个）

### 3. 池化（pooling）

紧跟卷积层之后，简化信息：

- **最大池化（max-pooling）**：$2\times2$ 区域只输出最大值 → $24\times24$ 变 $12\times12$
- 直觉：一旦找到某特征，**精确位置不如相对其他特征的粗略位置重要**；池化丢弃精确位置信息、减少后层参数
- 变体：**L2 池化**（取区域平方和的开方）

## 结构：卷积 → 池化 → … → 全连接 → softmax

```
28×28 输入
  → Conv(5×5 感受野, N 特征映射) → N×24×24
  → MaxPool(2×2)                → N×12×12
  → (可重复 ConvPool)
  → FullyConnected → … → Softmax(10)
```

卷积/池化层学**局部**空间结构，后面全连接层学**抽象**层面、整合全局信息——这是 CNN 的通用模式。

## 关键收益：参数数量锐减

| 层 | 参数 |
|---|---|
| 卷积层（20 特征映射 × $5\times5$） | $20\times(25+1)=520$ |
| 全连接（$784\to30$） | $784\times30+30=23{,}550$ |

全连接层参数是卷积层的 **40 多倍**。共享权重把参数从"每连接一个"降到"每特征映射一套"——训练更快，也让搭深层网络成为可能。

## MNIST 实战：从 97.8% 到 99.67%

Ch.6 一步步加技术，性能爬升：

| 架构/技术 | 测试准确率 |
|---|---|
| 全连接单隐层 100 神经元（基线） | 97.80% |
| + 1 层 ConvPool | 98.78% |
| + 第 2 层 ConvPool | 99.06% |
| + **ReLU**（换掉 sigmoid）+ L2 | 99.23% |
| + **数据增广**（平移/旋转/倾斜，5 万→25 万图） | 99.37% |
| + 更大全连接 + **dropout** | 99.60% |
| + **集成**（多网络投票） | **99.67%** |

错误率从 2.2% 降到 0.33%，最终 10,000 张测试图只错 33 张，接近人类水平。

## 为什么 CNN 能训得动深层网络？

呼应 [[TrainingMechanics]] 的梯度消失/爆炸：

1. **共享权重大幅减少参数** → 学习问题变容易
2. **ReLU 替代 sigmoid** → 因子 $w\sigma'(z)$ 里的 $\sigma'$ 从 $\le1/4$ 提到 $1$，缓解连乘衰减
3. **更强正则化**（dropout + 数据增广）→ 复杂网络不过拟合
4. **GPU 长时间训练**

> 一句话：**CNN 靠"局部感受野 + 共享权重"利用平移不变性把参数砍掉一个量级，靠池化浓缩信息，靠 ReLU 稳住梯度——三者让"深度 + 图像"从难训变成可行。**

## 在本项目中的体现

- 项目主体用 [[Transformer]]，**未采用 2D CNN**；CNN 仅作为对比 baseline 出现：`Compare-Inbetweening-Methods` 里的 **MC-Trans**（BERT encoder + **1D 卷积**）与 **FCN**（Fully-Convolutional Network，Conv1d）
- [[MotionInbetweeningTwoStage]] 对比表指出 CNN 类（FCN）的局限：**感受野限制长程建模、输入尺寸常需 2 的幂、变长需 padding**——这正是项目选择 Transformer（全局注意力）的原因
